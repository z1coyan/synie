# 履约需求

## 概述

履约需求模块是销售承诺与车间/采购执行之间的**内部需求中间层**。计划员将多张销售订单条目（可跨单）勾选纳入，或手工建无客户来源的独立需求（如参展样品）；此外车间还可在生产工单上经「生成物料需求」动作派生需求单草稿（来源=生产工单），销售退货单审核后可经「生成补货需求单」按钮派生补货需求单草稿（来源=销售订单条目或手工行，见 [销售退货](./销售退货.md)）。确认后锁口径。行上**不再选择单一履约方式**——如何消化数量由**安排**子表表达，同一行可混用生产、采购、委外、库存与关闭。

边界：库存/关闭安排只登记意图、不扣库存不建单；不排有限产能；界面可称「需求单」，勿称「物料需求单」。

## 核心概念

- **履约需求单**：头状态 草稿 → 已确认 → 已关闭（+作废）；仅草稿可改可删；有未作废下游（生产工单、已审核未作废采购/委外订单条目、手工安排）时不可作废。见 [术语表](../术语表.md)。
- **指派类型**：单头必填的纯路由声明（采购 / 生产 / 库存 / 关闭，委外归采购侧）——表达「这张单由谁消化」；不占量、不约束行级安排（行仍可混用五类安排），类型=关闭不联动状态机。类型=生产时下发车间必填，其余类型下发车间必须为空。
- **履约需求行**：物料 + 数量 + 需求日（**必填**）+ 可选来源（销售订单条目 / 生产工单，二选一互斥，或皆空的手工行）；**无行级履约方式**。来源字段创建时定型、之后不可改（手工行不可事后补挂）。
- **行图纸快照**：需求行保存（创建/改物料）时把物料图纸挂接复制到行上，仅作行内展示；生产工单创建时图纸仍从物料主数据取，不回需求行取。
- **单头需求日**：可空；新建需求行时作为行需求日的默认值（含销售勾选带入），另提供「批量带入」把单头需求日刷新到全部既有行（覆盖已填值）；改单头本身不追溯既有行。
- **安排**：行上出口事实，类型 = 生产 / 采购 / 委外 / 库存 / 关闭。生产/采购/委外由工单创建或采购·委外订单审核**倒写**；库存与关闭手工维护。
- **已安排数量 / 已完成数量**：行上两个只读主投影（默认单位）——已安排看占坑，已完成看履行（含库存/关闭即完成）。采购分量可另显已下单/已收细分。投影单向：采购/委外退货回减订单条目已收数量时，需求行已完成**不反转**（退货后的补货由人工判断或销售退货的补货按钮发起，不自动重开需求）。
- **需求超安排比例**：行级超安排容差；关闭安排不吃容差。
- **销售占用**：已确认未作废需求单上有销售来源的行，Σ base 数量 ≤ 订单条目订购 base + 该条目已审核销售退货量（挂源行部分——客户退回后仍欠客户的量，无退货时退化为订购 base）；草稿不占、确认占量，作废释放占用；校验时点仍为确认时，不为「退货作废导致既有需求超限」新增拦截。
- **下发车间**：需求单头级的指派部门，须与需求单同公司且未停用；仅指派类型=生产时可填。

## 功能清单

### 建单与行维护

- 选择公司、业务日期、**指派类型**（必选）、可选单头需求日、备注；新建时业务日期默认当天，单号由系统按编号规则生成（不接受手填、创建后不可改）。类型=生产时下发车间必选，其余类型下发车间禁用并清空。
- 需求行与需求单基本信息在同一录入页面连续展示；从「需求行」列表也可直接新建整张需求单。
- 草稿可增删改行：物料、单位（限默认/转换单位）、数量（>0）、需求日（**必填**，新建行默认取单头需求日，可用「批量带入需求日」把单头值刷到全部行）、行备注（**无履约方式字段**）；来源销售订单条目创建时定型、之后只读。
- 手工行无销售来源合法（且不可事后补挂）；有来源时硬校验不超该条目可占用。
- 可跨多张已审核未关闭销售订单勾选纳入；同一销售条目可拆成多条需求行。
- 行保存时复制物料图纸挂接到行（仅行内展示快照）；删行/删单时挂接一并清理。
- 新建可「保存」或「保存并审核」。

### 工单派生（生成物料需求）

- 生产工单上的「生成物料需求」动作是第三个建单入口：按工单 BOM 快照展开配料，逐行选定去向（某车间 / 采购 / 不需要）后一次提交，按去向分组生成多张需求单**草稿**——每个目标车间一张（头已填下发车间，指派类型=生产）、采购向一张（下发车间为空，指派类型=采购，留采购/委外勾选池消化）。数量口径与动作可用条件见 [生产工单](./生产工单.md)「生成物料需求」。
- 派生行来源=生产工单（行上「来源工单」只读链接，与销售来源互斥），不占销售占用；需求日默认=来源工单需求日（工单无需求日落派生日），可改。
- 派生出来的是草稿：车间可改可删后再确认，下游车间与采购在确认后接力；子车间开工单后可再次派生，多级展开不限深度。
- 工单作废/删除时级联删除仍未确认的派生草稿；已确认的派生单只警告不拦截。改工单数量不回溯已派生草稿。

### 安排子表

- 已确认需求行展示安排子表：类型、数量、下游单据链接（工单号/订单号等）、状态。
- **生产**：创建生产工单时倒写；工单作废释放。
- **采购 / 委外**：采购或委外订单审核挂本来源行时倒写；订单作废释放。草稿订单不占已安排。
- **库存**：手工加行，保存即占已安排与已完成，不扣库存。
- **关闭**：手工加行，数量硬卡 ≤ 剩余可安排（不吃超安排比例），保存即占已安排与已完成。
- 列表展示已安排数量、已完成数量、剩余可安排。

### 下发车间与改派

- 草稿在表单里填改指派类型与下发车间（类型=生产时车间必填，其余类型必须为空）；已确认后走行动作「下发/改派」（独立权限，写审计），可同时改指派类型与下发车间并过同一联动校验，已关闭/作废不可再改。
- 计划员可下发任意车间，不受自身部门约束。
- 车间角色按「本部门」数据范围只看到下发到本车间的需求单，并从其行开工单；跨车间需求拆单。

### 审核 / 关闭 / 作废

- **审核**：至少一行；审核成功后状态进入已确认并锁定行物料数量等口径。
- **关闭**（整单）：仅已确认可关；关闭后不可再新安排（不可再开工单/勾选下单/加库存关闭安排）。
- **作废**：仅已确认且无未作废下游时可作废；草稿请直接删除。作废释放销售占用。

### 行完成

- 自动完成：可安排剩余 ≤ 0（受需求超安排比例）且已完成数量 ≥ 需求数量。
- **无**行级「点完成」按钮；放弃用关闭安排，现货用库存安排。

### 权限与编号

- 独立权限资源（计划侧）；写操作进审计；编号规则可配。
- 车间角色持需求单的查看 / 改 / 确认 / 删除（**无创建**），数据范围限「下发到本车间」：派生全程自助（含对自己派生草稿的改与审），但手工建单与销售勾选入口仍关闭，界面上建单按钮自动隐藏。

## 业务流程

1. 计划新建草稿需求单，手工加行或从销售勾选，确认。
2. 车间从行开（多张）工单 → 倒写生产安排；采购勾选带入下单审核 → 倒写采购/委外安排；计划可对手工库存/关闭安排。
3. 车间在工单上「生成物料需求」→ 按去向拆成多张需求单草稿 → 车间改审后，下游车间 / 采购接力（可再开工单继续向下派生）。
4. 入库回写已完成；排满且履行完 → 行自动完成。整单可关闭收敛待办。
