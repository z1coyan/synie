# 生产BOM

## 概述

生产 BOM 模块承载制造侧的配方主数据：为物料建立单层 BOM——一张 BOM 由配料、工艺路线、副产品三块内容组成，并配套工序与工艺模板两个全局基础主数据，服务生产与工艺管理人员。同一物料可建多张 BOM（不同配方方案），以独立编号区分；BOM 是生产执行层（工单扣料、报工、完工入库、成本归集）与委外订单「按哪张配方发料」取配方的锚点。BOM 跟随物料全局共享、不分公司。

边界：配方主数据带**草稿 / 启用 / 停用**生命周期——工艺路线只描述「怎么做」，不驱动执行、不派生任何库存或财务后果。执行层见 [履约需求](./履约需求.md)、[生产工单](./生产工单.md)、[生产入库](./生产入库.md)（工单可选启用中 BOM 并快照，不自动扣料）；委外订单条目可引用启用中 BOM 并按其代入发料/副产物清单（代入为快照复制，见 [采购订单](./采购订单.md)）；扣料/工序报工/工序级外协单据流/BOM 版本树仍不在本期。

## 核心概念

- **BOM**（物料清单）：挂在物料上的单层配方主数据；**一物料可多张**（同一成品的不同配方方案，如自用/委外），以**独立编号**为唯一键。状态 **草稿 → 启用 ⇄ 停用**。多级结构靠半成品物料各自挂 BOM 嵌套形成，系统不建 BOM 树实体。见 [术语表](../术语表.md)。
- **BOM 编号**：每张 BOM 的唯一标识，由系统按编号规则生成（不接受手填），全局唯一，创建后不可改；是工单/委外等下游指名引用的锚点。
- **方案名称**：可空文本，辅助在列表与选择器里区分同一物料的多张 BOM。
- **启用 / 停用**：仅**启用**可被新生产工单、新委外订单选入；停用后新单不可选，已快照/已引用单据不受影响。启用与停用可互转。
- **配料行**：BOM 的子物料行——子物料 + 单位 + 单位净用量（每 1 默认单位母物料的净消耗）+ 可空损耗率；平铺清单，不记录投料工序。
- **损耗率**：配料行上的可空比率，空即无损耗；理论耗用 = 净用量 ×（1 + 损耗率）。
- **工艺路线**：挂在 BOM 上的工序子表（每 BOM 私有），行 = 工序引用 + 顺序 + 工艺要求文本 + 外协标记，只描述工序顺序与要求。
- **外协标记**：工艺路线行上的布尔标记，表示该工序通常外发加工；不指定供应商、不产生任何单据。
- **副产品行**：BOM 上声明的联产出行（如铜屑、网屑）——物料 + 单位 + 单位产出量（每 1 默认单位母物料）；本期仅作声明。
- **工序**：全局共享的工序主数据（如冲网、分切、焊接成筒、CNC），被路线行与模板行引用。
- **工艺模板**：独立可维护的工艺路线模板主数据；建 BOM 路线时选模板复制带入，此后模板再改不影响已建 BOM（快照语义）。

## 功能清单

### BOM 新建与编辑

- 在物料上建 BOM：选择物料 + 编号 + 方案名称（可空）+ 备注，保存为**草稿**或直接**启用**；**一物料可建多张**。
- 编号由系统按编号规则生成、全局唯一，不接受手填、创建后不可修改。
- BOM 跟随物料全局共享，不分公司、无公司选择器。
- 创建后不可换物料——换物料 = 删旧（仅草稿）或停用后另建。
- 状态：**草稿 → 启用 ⇄ 停用**。启用后配料/路线仍可改；已快照到工单的配方不追溯（见 [生产工单](./生产工单.md)）。
- **仅草稿可物理删除**（级联配料/路线/副产品）；启用过之后只停用不删。已建有启用/停用 BOM 的物料删除规则仍受引用约束。
- 新工单/新委外选择器只列**启用中**且母物料匹配的 BOM。
- 生产工单内可嵌套完整创建流程（母物料锁定为工单物料），保存后的 BOM 进入本模块主数据。
- 增删改查需具备 BOM 的相应权限，操作接审计。

### 配料行维护

BOM 的配料清单，逐行维护，行 = 子物料 + 单位 + 单位净用量 + 损耗率 + 行备注。

- 单位净用量必填且大于 0，语义钉死为「每 1 默认单位母物料的净消耗」。
- 损耗率可空、不为负；空即无损耗，理论耗用 = 净用量 ×（1 + 损耗率）。
- 行单位限该子物料的默认单位或其单位转换单位（同销/采单据行单位约束）。
- 子物料不能是 BOM 母物料自身（保存校验）；多级间接成环（A 配料 B、B 配料 A）不硬校验，留待树展开视图检测截断。
- 平铺清单，不记录投料工序（投料时点待执行层需要时再补列）。
- 行维护视为 BOM 维护的一部分，不设独立权限点：读随 BOM 读权限，增删改随 BOM 编辑权限（同物料单位转换先例）。

### 工艺路线维护

BOM 的工序子表，每 BOM 私有，逐行添加，行 = 工序 + 顺序 + 工艺要求文本 + 外协标记。

- 工序从工序主数据中选择；工艺参数与要求走行内自由文本，不在工序主数据上结构化。
- 外协标记默认否；为是仅表示该工序通常外发加工，不指定供应商、不产生任何外协单据。
- 路线不带生产数量、不驱动执行、不派生库存/财务后果。
- **从工艺模板带入**：本 BOM 尚无路线行时，可选一份工艺模板，按其行顺序复制带入为本 BOM 私有路线行（已有路线行则拒绝带入，避免混入两套路线）；复制后与模板脱钩——模板日后再改不影响已建 BOM（快照语义，同系统「改默认不追溯」惯例）。带入动作复用 BOM 编辑权限，不设独立权限点。
- 行权限同配料行：读随 BOM 读、增删改随 BOM 编辑。

### 副产品行维护

BOM 上声明的联产出清单，行 = 物料 + 单位 + 单位产出量 + 行备注。

- 单位产出量必填且大于 0，语义为「每 1 默认单位母物料的联产出量」。
- 行单位限该物料默认单位或其转换单位；副产品物料不能是母物料自身。
- 本期仅作声明，不产生入库或成本后果，是将来执行层扣料/完工入库/成本分摊的锚点。
- 行权限同配料行。

### 工序维护

全局共享的工序主数据，字段 = 编号 + 名称 + 备注。

- 编号由系统按编号规则生成（初始化预置：`M(O)-` + 4 位补零序号，如 `M(O)-0001`）、全局唯一，不接受手填、创建后不可修改。
- 名称必填，不强制唯一。
- 被任一 BOM 工艺路线行或工艺模板行引用的工序不可删除，须先移除相关行。
- 增删改查需具备工序的相应权限，操作接审计。

### 工艺模板维护

全局共享的工艺路线模板主数据，头 = 编号 + 名称 + 备注，行 = 工序 + 顺序 + 工艺要求文本 + 外协标记（结构同 BOM 工艺路线行）。

- 编号由系统按编号规则生成（初始化预置：`M(T)-` + 4 位补零序号，如 `M(T)-0001`）、全局唯一，不接受手填、创建后不可修改。
- 模板可改可删，删除时模板行级联删除；模板的改删均不影响已从它带入路线的 BOM（快照语义）。
- 模板行维护不设独立权限点：读随模板读权限、增删改随模板编辑权限。
- 增删改查需具备工艺模板的相应权限，操作接审计。

### 权限与菜单

- 权限分三套：BOM、工序、工艺模板，均为标准增删改查；三类 BOM 行与模板行不设独立权限点（口径见上文各节）。
- 菜单入口在生产管理「计划」组（与履约需求单同组）：BOM、工序、工艺模板三个入口。

## 业务流程

建配方动线：先在工序主数据中维护好所需工序 → （可选）把常用工序组合维护成工艺模板 → 在目标物料上建 BOM（草稿）→ 逐行录入配料行 → 从工艺模板复制带入工艺路线（或逐行手工建行、按需标外协）→ 如有联产出再录副产品行 → **启用**后方可供工单/委外选用。日后换配方可直接改启用中 BOM（已快照工单不追溯），退出主路径则**停用**；误建草稿可删。
