# 委外退货

## 概述

委外退货模块承载委外加工链路的**成品退回**：加工不良的成品退回协作方返修，审核后扣减本公司仓库存、回减委外订单条目已收数量。服务仓管。退货是**纯数量单**——无金额、不过总账、不进对账：材料已消耗物化、副产物不联动，加工费只对最终验收合格的收货付一次（返修后重新委外入库时照常计加工费、照常进采购对账）。

边界：无反审核/红冲；不回补外协仓材料、不退副产物（材料视为已消耗）；内部公司对手只记我方账；无补货需求单按钮。本篇为拷问定稿的设计基线，实现后以代码行为校准。

## 核心概念

- **委外退货单**：成品退回单据，纯数量不过总账，状态机 草稿→已审核→（已作废）。见 [术语表](../术语表.md)。
- **退货条目**：两类行——**源单行**必挂已审核未作废委外入库条目（物料口径随源行快照带入），**手工行**自填物料/数量（无金额字段）。
- **已退数量**：委外入库条目上默认单位累计，退货审核加、作废减；剩余可退 = 入库数量 − 已退数量；源单行退货量不得超过剩余可退。见 [术语表](../术语表.md)。
- **已收数量回减**：挂源行的退货审核时，委外订单条目已收数量同步回减，未收缺口重现；返修送回后照常走委外入库（加工费此时才计、才进对账）。需求行已完成不反转。手工行只动库存。
- **已对账拦截**：源入库条目存在非零已对账数量（加工费已被生效中采购对账单消耗）时**禁止退货**，须先撤回/作废相关对账单——保证同一批成品的加工费在对账池里只出现一次。见 [采购对账](./采购对账.md)。
- **物料快照**：行保存时冻结物料快照与图纸挂接，口径与委外入库条目一致。

## 功能清单

### 列表视图

- 双 tab：**退货条目**（默认）与**退货单**；共用退货单抽屉。
- **退货条目** tab 可直接「新建退货单」；草稿单条目提供行操作「审核整单」。
- 菜单：采购管理 → 委外 → 委外退货。

### 退货录入

- 整单草稿为唯一写边界（同委外入库先例）。
- 头：公司（建后不可换）、退货单号（系统按编号规则生成，独立系列）、退货日期、对手（供应商/内部公司，须与所引委外入库单一致）、默认仓库（可空，新建行预填）、备注。**无过账日期、无表底借贷科目**（不过总账）。
- 源单行：委外入库条目（选择器只列同公司、同对手、已审核未作废、剩余可退 > 0 且**已对账数量为零**的条目）、数量（≤ 剩余可退）、单位（随源行）、退货出仓（必填，本公司启用叶子仓）、行备注。
- 手工行：物料、单位、数量（>0）、退货出仓（必填）、行备注。
- 两类行可混，可跨多张委外入库单；公司、对手须一致（无金额，无币种约束）。

### 审核

- 至少一行；行仓复检；源单行复检剩余可退与已对账拦截。
- 同一事务：写负向库存分录（成品出本公司仓）；挂源行的行累加委外入库条目已退数量、回减委外订单条目已收数量。**不写总账、不动外协仓、不动副产物**。

### 作废

- 仅已审核可作废：库存分录作废，回滚已退数量与已收数量（过负库存校验）。

### 与订单交叉

- 已收数量回减后，委外订单条目未收缺口重现，返修送回后照常委外入库（超收校验口径内）。
- 有已审核退货时订单作废规则不变。

## 业务流程

委外入库 → 发现加工不良 → 新建委外退货单（从入库单导入行，已对账的须先撤回对账）→ 审核（成品出仓 + 已收回减）→ 协作方修好送回 → 照常委外入库（加工费此时计并入采购对账）。
