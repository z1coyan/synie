# 采购退货

## 概述

采购退货模块承载对供应商/内部公司的**退货出库**：从已审核采购入库单导入行登记退回，或手工建行（系统外历史退货），审核后扣减库存、回减订单已收数量，有金额时按头上借贷科目冲减未开票应付。服务采购内勤与仓管。退货与采购入库平级，退货款与入库款的勾稽由采购对账单同池净额承载（见 [采购对账](./采购对账.md)）。

边界：不做存货估值（同采购入库）；无反审核/红冲；内部公司对手只记买方账，不自动镜像卖方入库；退货后由供应商重送补齐——已收数量回减后未收缺口自然重现，不提供补货需求单按钮（需求行链路亦不反转，见 [履约需求](./履约需求.md)）。

## 核心概念

- **采购退货单**：退货出库单据，状态机 草稿→已审核→（已作废）。见 [术语表](../术语表.md)。
- **退货条目**：两类行——**源单行**必挂已审核未作废采购入库条目（物料/价税口径随源行快照带入），**手工行**自填物料/数量/含税单价/税率。
- **已退数量**：入库条目上默认单位累计，退货审核加、作废减；剩余可退 = 入库数量 − 已退数量；源单行退货量不得超过剩余可退，手工行不受限。已退与已对账互不干涉。见 [术语表](../术语表.md)。
- **已收数量回减**：挂源行的退货审核时，订单条目已收数量同步回减，未收缺口重现，供应商重送后照常入库；沿「订单条目→需求行」的需求行已完成**不反转**（退货后的补货由人工判断，不自动重开需求）。手工行只动库存。
- **已对账数量**：退货条目上默认单位累计，由生效中的采购对账单同步；退货条目与采购/委外入库条目同池混勾，退货行对账金额取负。见 [采购对账](./采购对账.md)。
- **物料快照**：行保存时冻结物料快照与图纸挂接，口径与入库条目一致。见 [术语表](../术语表.md)。

## 功能清单

### 列表视图

- 双 tab：**退货条目**（默认）与**退货单**；共用退货单抽屉。
- **退货条目** tab 可直接「新建退货单」；草稿单条目提供行操作「审核整单」。
- 菜单：采购管理 → 交易 → 采购退货。

### 退货录入

- 整单草稿为唯一写边界（同采购入库先例）。
- 头：公司（建后不可换）、退货单号（系统按编号规则生成，独立系列）、退货日期、过账日期、对手（供应商/内部公司）、原币与汇率（默认公司本币；含手工行时全单金额以此换算）、默认仓库（可空，新建行预填）、备注。
- 源单行：入库条目（选择器只列同公司、同对手、已审核未作废且剩余可退 > 0 的采购入库条目）、数量（≤ 剩余可退）、单位（随源行）、退货出仓（必填）、行备注；物料/价税/订单快照随源行带入。
- 手工行：物料、单位、数量（>0）、含税单价、税率、退货出仓（必填）、行备注。
- 两类行可混，可跨多张入库单；公司、对手、原币须一致。
- 表底：借方科目（未开票应付角色）、贷方科目——**草稿保存即必填**；新建或换公司时按该公司默认过账科目（入库槽）整组覆盖代入。

### 审核

- 至少一行；行仓须本公司启用叶子仓；源单行复检剩余可退。
- 写负向库存分录（出仓）；有金额时写总账两行（借未开票应付、贷选定科目，方向为采购入库反转）。
- 挂源行的行：累加入库条目已退数量、回减订单条目已收数量。
- 整单金额为零：跳过总账，但头上借贷科目仍须已填。

### 作废

- 仅已审核可作废：库存/总账分录作废，回滚已退数量与已收数量（过负库存校验）。
- 任一条目存在非零已对账数量则整单不可作废，须先撤回/作废相关采购对账单。

### 与订单交叉

- 已收数量回减后，订单条目未收缺口重现，可照常入库（不超收校验口径内）。
- 有已审核退货时订单作废规则不变（入库/退货均须先处理）。

## 业务流程

入库 → 质检/使用发现不良 → 新建采购退货单（从入库单导入行或手工行）→ 审核（出仓 + 冲未开票应付 + 已收回减）→ 供应商重送后照常采购入库 → 下次对账时退货行与入库行同池净额勾稽 → 收票。
