# 销售退货

## 概述

销售退货模块承载客户/内部公司的**退货回库**：从已审核销售发货单导入行登记退回，或手工建行（系统外历史退货），审核后增加库存、回减订单已发数量，有金额时按头上借贷科目冲减未开票应收。服务销售内勤与仓管。退货与销售发货平级，退货款与发货款的勾稽由销售对账单同池净额承载（见 [销售对账](./销售对账.md)）；退货后要不要补发给客户，由单头「生成补货需求单」按钮转交履约需求链路（见 [履约需求](./履约需求.md)）。

边界：不做存货成本/销项税拆分（同销售发货）；无反审核/红冲；不做装箱清单；内部公司对手只记卖方账，不自动镜像买方入库。

## 核心概念

- **销售退货单**：退货回库单据，状态机 草稿→已审核→（已作废）。见 [术语表](../术语表.md)。
- **退货条目**：两类行——**源单行**必挂已审核未作废销售发货条目（物料/价税口径随源行快照带入），**手工行**自填物料/数量/含税单价/税率（处理无源单可挂的退货）。
- **已退数量**：发货条目上默认单位累计，退货审核加、作废减；剩余可退 = 发货数量 − 已退数量；源单行退货量不得超过剩余可退，手工行不受限。已退与已对账互不干涉（已对账消耗的货仍可退，冲减走后续对账净额）。见 [术语表](../术语表.md)。
- **已发数量回减**：挂源行的退货审核时，订单条目已发数量同步回减，未发缺口重现，可照常再发货；手工行无订单条目，只动库存。
- **已对账数量**：退货条目上默认单位累计，由生效中的销售对账单同步（确认/结单加、撤回/作废减）；退货条目与发货条目同池混勾，退货行对账金额取负。见 [销售对账](./销售对账.md)。
- **补货需求生成**：已审核单单头按钮，一键把本单退货行转成一张履约需求单草稿。见 [术语表](../术语表.md)。
- **物料快照**：行保存时冻结编号/名称/规格/客户料号/单位名并复制图纸挂接，口径与发货条目一致。见 [术语表](../术语表.md)。

## 功能清单

### 列表视图

- 双 tab：**退货条目**（默认）与**退货单**；共用退货单抽屉。
- **退货条目** tab 可直接「新建退货单」；草稿单条目提供行操作「审核整单」，与销售发货同一交互先例。
- 菜单：销售管理 → 交易 → 销售退货。

### 退货录入

- 抽屉单 tab（无装箱清单）；查看/编辑/新建三态同构；整单草稿为唯一写边界（同销售发货先例，任一条目失败整单不生效）。
- 头：公司（建后不可换）、退货单号（系统按编号规则生成，独立系列）、退货日期、过账日期、对手（客户/内部公司）、原币与汇率（默认公司本币，汇率 1；含手工行时全单金额以此换算）、默认仓库（可空，新建行预填）、备注。
- 源单行：发货条目（选择器只列同公司、同对手、已审核未作废且剩余可退 > 0 的发货条目）、数量（≤ 剩余可退）、单位（随源行）、退货入仓（必填）、行备注；物料/价税/订单快照随源行带入。
- 手工行：物料、单位（限默认/转换单位）、数量（>0）、含税单价、税率、退货入仓（必填）、行备注。
- 两类行可混，可跨多张发货单；公司、对手、原币须一致（源行原币随其发货快照，须与单头原币一致）。
- 表底：借方科目、贷方科目（未开票应收角色）——**草稿保存即必填**；新建或换公司时按该公司默认过账科目（发货槽）整组覆盖代入（无默认则清空）。
- 行保存时同步冻结物料快照与图纸挂接。

### 审核

- 至少一行；行仓须本公司启用叶子仓；源单行复检剩余可退。
- 写正向库存分录（回库）；有金额时写总账两行（借选定科目、贷未开票应收，方向为销售发货反转）；源单行金额按发货条目快照口径，手工行按手填价税。
- 挂源行的行：累加发货条目已退数量、回减订单条目已发数量。
- 整单金额为零：跳过总账（不造名义分录），但头上借贷科目仍须已填。

### 作废

- 仅已审核可作废：库存/总账分录作废，回滚已退数量与已发数量（过负库存校验）。
- 任一条目存在非零已对账数量（被生效中销售对账单消耗）则整单不可作废，须先撤回/作废相关对账单。

### 生成补货需求单

- 已审核单单头按钮，把本单全部退货行转成**一张履约需求单草稿**：行 = 退货行物料 + 数量（折默认单位），需求日默认 = 退货日期；源单行来源 = 对应销售订单条目，手工行 = 无来源手工行。生成的需求单**指派类型默认 = 库存**（现货补发是最常见补货形态，纯路由意图，计划员可在草稿改派），行备注留「退货补货：单号」线索，需求单头以**来源退货单**字段留痕。
- 可重复点击，每次生成一张新草稿；退货单头留已生成需求单链接供追溯；重复生成的超量由需求单确认时的销售占用校验兜底（占用上限 = 订购 + 已退，见 [履约需求](./履约需求.md)）。
- 生成的是草稿：计划员按现有流程改删后再确认，本模块不替计划员做补货决策。

### 与订单交叉

- 已发数量回减后，订单条目未发缺口重现，可照常发货（不超发校验口径内）。
- 有已审核退货时订单作废规则不变（发货/退货均须先处理）。

## 业务流程

发货 → 客户退回 → 新建销售退货单（从发货单导入行或手工行）→ 审核（回库 + 冲未开票应收 + 已发回减）→ 需要补发时点「生成补货需求单」→ 下次对账时退货行与发货行同池净额勾稽 → 开票。
