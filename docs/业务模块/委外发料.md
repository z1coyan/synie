# 委外发料

## 概述

委外发料模块承载委外加工链路的**材料发出**：从委外订单条目约定的发料清单取行，把材料从本公司仓移入绑定协作方的外协仓，审核后在库存账上留下「调出仓负＋外协仓正」的移动记录，并累加发料清单行的已发料量。服务仓管。

边界：发料是仓间移动、所有权不变——单据无金额、不过总账（同手工调拨不生凭证先例）。成品回收、外协材料扣减与加工费挂账由**委外入库单**承载（见 [委外入库](./委外入库.md)）；「协作方处还压着多少我方材料」直接看外协仓结存（见 [库存物料](./库存物料.md)）。

## 核心概念

- **委外发料单**：对协作方的委外材料发出单据，状态机 草稿→已审核→（已作废）。见 [术语表](../术语表.md)。
- **发料条目**：发料单的行，必挂委外订单条目下的**发料清单行**（唯一取行来源）；材料与单位以清单行为准强制带出、不可手改。
- **发料清单**：委外订单条目下「需发给协作方的材料」子表，在采购订单上维护（见 [采购订单](./采购订单.md)）。
- **已发料量**：发料清单行上按材料默认单位累计的已发出量；发料审核加、作废减；剩余可发＝清单数量−已发料量；**超发不硬拦**（无容差设置），超额仅展示。
- **外协仓**：货物存放在协作方处的我方仓，一仓绑定一个协作方；发料审核把材料从调出仓移入外协仓。见 [库存物料](./库存物料.md)。

## 功能清单

### 列表视图

- 页面分两个 tab（子路由，URL 可直达）：**发料条目**（默认视图，行级明细——公司、发料单号、发料日期、发料状态、订单号、对手、行快照口径的材料编号/名称/规格、单位、数量、折算数量（材料默认单位）、调出仓、外协仓；默认按发料日期倒序）与**发料单**（整单列表，含审核/作废/删除动作）。
- 两个 tab 共用同一个发料单抽屉（新增/查看/编辑三态）；「新建发料单」入口两个 tab 都有；发料条目 tab 草稿单提供行操作「审核整单」，与发料单 tab 的「审核」一样先弹整单条目核对确认框。
- 菜单：采购管理 → 委外 → 委外发料。

### 发料录入

- 头：公司（新建必选，创建后不可换）、发料单号（留空按编号规则自动取号，也可手填；独立系列，与其他单据编号互不干扰）、发料日期（默认当天，可改即补录）、对手（供应商/内部公司，不能是单据公司自身，须与所引委外订单一致）、默认调出仓/默认外协仓（均可空，仅新建行预填）、备注（对内，带入库存分录摘要）。
- 行：从发料清单行选择器取行——选择器只列同公司、同对手、**已审核委外订单**且剩余可发大于零的清单行（可跨多张委外订单合并向同一协作方发货）；选定后材料、单位由清单行带出锁定，订单号快照落行；另录数量（大于零）、行调出仓（必填，本公司启用叶子仓）、行外协仓（必填，只列绑定当前对手的外协仓）、行备注。
- 行调出仓与外协仓不能是同一仓。
- 发料单无金额、无币种约束：跨单取行只要求全部行订单的公司、对手与单头一致。
- 头关键字段锁：已有发料条目时公司/对手不可再改（须先删行）；行保存即冻结材料/单位快照。

### 审核

- 仅草稿单可审核；审核前必须至少有一行发料条目。
- 审核同一事务内：逐行复检行调出仓与行外协仓、复检各行订单仍为已审核且公司/对手与本单一致，然后写「调出仓负＋外协仓正」库存分录（来源类型委外发料），并按行累加对应发料清单行的**已发料量**（材料默认单位口径）。
- 超出发料清单数量发料不被硬拦、无容差设置——剩余可发可为负，仅作展示（「多给料」不被系统卡死）。
- 审核后单据锁死：无反审核、无关闭态。

### 作废

- 仅已审核单可作废：库存分录打作废标记（作废减外协仓库存，照常过负库存校验，致负则拒绝作废），已发料量同步扣减回滚。
- 仅草稿单可删除，发料条目随单一并删除。

## 业务流程

委外订单（已审核、条目配好发料清单）→ 新建委外发料单（选公司与对手，从头默认仓预填行仓）→ 从发料清单取行、逐行定调出仓与外协仓 → 保存草稿 → 审核（材料移入外协仓、已发料量累加）→ 出错在审核前改删，审核后作废重开。外协仓结存随时在库存余额查看。
