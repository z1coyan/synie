# ADR：工单物料需求派生（嵌件/材料再分流）

2026-08-06，拷问访谈定案（grill-with-docs）。

- **问题**：工单带出 BOM 配料（嵌件/其他材料）后，车间需要把这些材料再通过履约需求单下给其他车间或采购；现有需求行来源只有销售条目勾选与手工行，无「来源=工单」的派生机制，也无净需求概念。
- **工单加「生成物料需求」动作，派生需求单草稿**：按工单 BOM 快照展开配料 → 生成履约需求单**草稿**（草稿→确认的人工闸门不变），拒绝全自动派生确认（脏 BOM 直接冲下游）与纯手工重录（没解决带出问题）。需求行新增来源类型**生产工单**（只读链接），派生行无销售来源、不占销售占用。
- **数量口径计损耗**：毛需求 = 净用量 ×（1 + 损耗率，空按 1）× 工单数量，即 BOM 文档既有「理论耗用」口径，不发明新概念；生成行沿用配料行单位（限子物料默认/转换单位）。
- **参考库存快照，不锁不预留**：生成时每行带出**本公司全部仓库现有库存合计**（换算到行单位）作参考列，默认净需求 = 毛需求 − 参考库存，人可改；库存是生成瞬间快照，系统不担保、不预留、不扣减——拒绝引入库存预留/分配子系统。参考库存足够的行由人在动作内选「不需要」不带出。
- **去向逐行选，按去向拆多张草稿**：动作界面逐行（可批量）选「某车间 / 采购 / 不需要」；每个目标车间生成一张草稿（头已填下发车间），采购向生成一张草稿（下发为空，留采购勾选池消化）。**拒绝**给物料加「默认来源/默认车间」主数据做自动预分流——同一嵌件多车间可做，默认数据会过期且错会自动流下去。
- **权限：车间经动作入口建单并自审**：车间角色授予履约需求单的创建+审核权限，但**仅限经工单「生成物料需求」动作入口**；车间仍不可手工建需求单、不可勾选销售条目。派生行无销售占用、无客户语义，计划闸门对这类行无增量价值。
- **轻联动，拒绝全联动**：工单**作废**时级联删除仍未删除的派生**草稿**（草稿本来可物理删，无审计负担）；已确认的派生单只警告不拦截（下游可能已执行，业务问题人收场）；工单**改数量不回溯**派生草稿（人改草稿或用关闭安排收敛）；重复点生成动作且存在未删除派生草稿时提示。与「BOM 快照脱钩、不追溯」先例一致。
- **多级自然递归，不做齐套**：子车间收到派生需求单后可开工单继续向下派生，不限深度（BOM 成环靠树展开检测截断先例）；工单开工/生产入库**不检查**子级材料需求是否履行——父需求行完成只由生产入库回写，与子级链无联动，系统不建齐套概念。
- **默认值**：派生行需求日默认 = 来源工单需求日，草稿可改（无提前期概念，要提前则手改）。
- **明确排除（本期）**：库存预留/分配、齐套检查、按 BOM 快照实扣料、物料「默认来源/默认车间」主数据、BOM 树实体、派生链与父需求行完成状态的联动。
- **实施时同步**：`docs/产品文档/履约需求.md`（来源类型、动作与拆单）、`docs/产品文档/生产工单.md`（生成物料需求动作）、`CONTEXT.md` 相关词条。
