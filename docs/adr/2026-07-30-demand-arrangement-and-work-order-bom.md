# ADR：履约安排混排 + 生产工单数量/BOM/图纸

2026-07-30，拷问访谈定案（grill-with-docs）。部分推翻 ADR 2026-07-24「一需求行一未作废工单、拆批只在需求行层」与 ADR 2026-07-25「行级履约方式严格匹配采购/委外」。

- **砍掉行级履约方式，安排升格为唯一出口事实**：同一履约需求行可混用生产/采购/委外/库存/关闭。拒绝保留「意图字段 + 执行可偏离」双真相。旧四态自制/外购/委外/库存不再挂行；放弃走**关闭安排**，现货走**库存安排**（均手工、不扣库存），取消行上「点完成」。
- **执行倒写安排，拒绝先占坑再执行**：生产安排随工单**创建**写入；采购/委外安排随订单条目**审核**写入（草稿不占，与全系统草稿哲学一致）；库存/关闭在需求侧保存即写。拒绝「计划先写安排再派生单据」的两段录入（可在 UI 封装，领域仍倒写）。
- **双投影：已安排数量 + 已完成数量**：已安排 = 未作废工单量 + 已审核采购/委外挂行量 + 库存安排 + 关闭安排；已完成 = 生产入库 + 采购/委外入库回写 + 库存 + 关闭。行完成 = 排满（可安排剩余≤0）且已完成≥需求。关闭硬卡≤剩余可安排（不吃容差）。
- **需求超安排比例**（新设置，覆盖旧需求超下单比例语义）：行级统一闸门，工单创建 / 采购·委外审核 / 库存·关闭保存共用；默认 0、0～100%。
- **生产工单：多张、可填数量、必挂需求行**：推翻「一需求行至多一张未作废工单、数量锁需求行」。默认数量=剩余可安排（不含容差超额）；改数量/作废仅进行中且无已审核生产入库，作废释放已安排。拒绝无来源独立工单（本期）。
- **工单可选 BOM，选后快照**：限本物料**启用中** BOM；配料/工艺路线/副产品复制为工单私有子表，与主数据脱钩；无已审核入库前可换选/手改/清空，有入库锁死。工单内嵌完整 BOM 创建组件（母物料锁工单物料），复用主数据校验。第一期仍不按快照扣料/报工。
- **工单图纸 = 创建时复制物料 drawing 挂接**：同订单/发货快照挂接先例；主数据后改不回溯；无图不拦建单。
- **BOM 生命周期改为草稿→启用⇄停用**：仅启用可选入新工单/新委外；仅草稿可物理删除；启用后仍可改主数据，已快照执行不追溯。推翻早期「单份可改可删、无启停」。
- **采购勾选池不再按履约方式过滤**：需求行已无方式字段；普通采购审核倒写采购安排、委外倒写委外安排。超量闸门改走需求超安排比例。
- **明确排除（本期）**：先安排后执行的计划占坑模型、无来源工单、工单按快照实扣料/工序报工、关闭与库存以外的「点完成」例外出口。
