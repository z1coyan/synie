# 对手地址从属单方、入口内嵌主体

地址是客户 / 供应商 / 内部公司的**从属子资源**（`party_type`+`party_id`，一址一方），不做跨主体共享地址簿，也不做独立地址菜单主入口——维护发生在主体抽屉「地址」tab，避免「先去地址总库配半天再挂接」。用途分收发货 / 通信办公 / 其他，同主体同用途至多一个默认。省/市/区用前端打包的中国行政区划 PCA 清单级联选填（存中文名，不设独立区划主数据表），街道门牌自由文本。本期不挂发货/入库单据字段，不碰发票票面地址电话与仓址。

**Considered options：** 独立地址主数据 + 多对多挂接（易生孤儿与总库 UX）；从属单方 + 可选跨主体引用（复杂度高且与客商分表不一致）。选用从属单方。区划不入库主数据表、不存国标码，避免与民政区划变更同步负担。
