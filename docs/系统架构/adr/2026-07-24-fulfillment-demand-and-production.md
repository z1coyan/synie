# ADR：履约需求单与生产执行（工单 / 生产入库）

2026-07-24，拷问访谈定案（grill-with-docs）。

- **上中间层「履约需求单」，拒绝销售订单直连生产工单**：销售是客户承诺，车间不得见客户/销售单；部分销售不进生产、部分走外购/委外/现货、另有无客户独立需求（参展样品等）。中间层汇集「要落实什么」，再按行分流。拒绝「仅靠权限藏字段」的单层工单——待办无法表达非自制出口，也承载不了独立需求。界面可称「需求单」；领域名用**履约需求单**，避免「物料需求单」与领料语义撞车。
- **需求来源 = 跨单勾选销售条目 + 手工建单**：粒度按计划批次（可跨多张销售订单），非强制一销售单一张需求单；手工行无客户、无销售来源。有销售来源的数量硬校验不超订单可占用。销售审核 ≠ 进入生产；不点纳入需求则生产侧当不存在。
- **履约方式四态：自制 / 外购 / 委外 / 库存**：第一期仅「自制」派生下游；外购/委外/库存只登记意图，计划一点「已完成」离开待办，不自动生成采购订单或委外单。与 BOM 工艺路线行上的**外协标记**（工序常外发）分层，勿混。
- **头状态 草稿→已确认→已关闭（+作废）**：确认后锁口径；有未作废生产工单不可作废需求单。确认后改履约方式仅当该行无未作废下游。
- **生产工单 = 未完成数量容器，一需求行一未作废工单**：车间主任从已确认自制行生成；不存客户；第一期不建工序报工/工艺纸条数字化（现场工艺粗细是业务选择，不是本期系统骨架）。拆批在需求行层，不在工单层开多张。拒绝有限产能排产/APS。
- **完成靠生产入库削量，不靠报工点完成**：生产入库行必挂工单、物料与工单一致；可分次；审核写正向库存分录并累加已入，作废回滚。累计已入 ≥ 工单数量 → 工单完工并回写需求行完成。对齐销/采：**允许超入**，全局**生产入库超入比例**（默认 0、0～100%），审核硬拦。第一期只数量账，不扣料、无 WIP 仓、无副产品入库、无生产成本总账。
- **权限拆三套**：履约需求单（计划）、生产工单（车间主任生成）、生产入库（默认仓管）；车间不授销售订单/客户权限。
- **明确排除（第一期）**：有限产能与机台排程、工序级报工、领料与 BOM 自动扣料、外购/委外自动建单、委外发料收回加工费、副产品、工单成本与生产总账。
