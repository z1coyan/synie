# ADR：内置角色种子归初始化向导

2026-07-29。

- **背景**：Elixir 时代内置角色（admin/sales）由迁移种子插入（见 ADR 2026-07-18「初始化向导与初始化分层」）；Go/TS 重写只搬了表结构（`sys_role.builtin` 列与守卫均在），角色种子丢失——新环境跑完初始化向导后角色表为空，且界面按约定写不出持全域通配 `*` 的 admin 角色。
- **决策**：内置角色种子从迁移层移到初始化向导 complete 的基础种子环节（`server/src/platform/setup/service.ts` `seedBuiltinRoles`），与存储接入点、编号规则、计量单位、物料分类同环节、同事务、同幂等风格；迁移层只留表结构。本 ADR 取代 2026-07-18「初始化向导与初始化分层」中「内置角色由迁移种子」一条。
- **理由**：所有必要种子集中于 setup 完成动作一处，环境初始化语义单一（「跑完向导即可用」）；迁移保持纯结构、可随意重放，不背业务数据职责。
- **不变量**：全域通配 `*` 仍仅种子可写（写面由迁移种子变为 setup 种子，ADR 2026-07-18「权限通配加全域级 `*`」的写面锁定结论不变）；内置角色守卫（不可改删、授权只读）不变；sales 逐码清单与权限目录对齐，新权限点 fail-closed 不自动授予。**当前状态（2026-08-10）**：系统保护已收窄为仅 admin，其余预置角色可编辑；见 [2026-08-10-editable-preset-roles.md](./2026-08-10-editable-preset-roles.md)。
- **影响面**：仅新环境生效（complete 一次性，落旗后入口关闭）。存量环境已由 super_admin 旗标兜底；如需补内置角色，角色行与 sales 授权可界面重建，admin 的 `*` 授权须 SQL 直插（与旧 ADR「老环境永远补不出全权角色」的结论一致）。
