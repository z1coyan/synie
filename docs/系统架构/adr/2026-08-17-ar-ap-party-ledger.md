# ADR：应收应付往来明细（履约按条目、其余按来源单据）

2026-08-17，拷问访谈定案。废止 [ADR 2026-07-16](./2026-07-16-ar-ap-report.md)「下钻跳分录页」。

- **余额仍只认总账**：报表列与抽屉累计都从 `acc_gl_entry` 轧差（截至日、未作废、当前 tab 展示角色）。不从业务单据重算余额。
- **明细离开纯分录**：一张发票会落下多行分录（往来 + 税额 + 未开票冲回），按分录下钻对账读不动。抽屉一行默认 = 一张来源单据；销售发货/退货、采购入库/退货、委外入库按**条目**拆（与销/采对账单池同粒度）。总账仍整单过账，拆行是联查履约条目后的展示分配，尾差记最后一行。
- **取消点金额跳分录页**：改行尾「查看」开宽抽屉。单号点只读速览（仍受来源单据读权限）；能看报表就能看流水里的物料数量，不另要履约读权限。抽屉用 SynieDataGrid 的搜索/列筛选（内存读模型，不写 URL）。
- **倒排展示、顺跑累计**：日期用过账日期。第一行累计对截至日报表该对手展示列。金额是带符号本币价税合计（开票取价税合计，重分类只写累计列）。
- **本页不展示预收/预付列**：角色与净额公式保留；有人手凭证记到预收，净额仍减、只是少一列。其他应付款在应付 tab 与应付抽屉单独列。
