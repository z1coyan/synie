# 移动端

## 概述

Synie ERP 在手机与竖屏平板（视口小于 1024px）上的使用形态：全部列表页自动切换为**卡片模式**——每条记录一张卡片，纵向滚动浏览，查单、搜索、筛选、看详情、审批/确认类操作均可在移动端完成。移动端定位**读为主 + 轻操作**；建单、编辑、批量操作（默认）、导入导出、打印等重操作不在移动端提供，回桌面完成。

## 核心概念

- **卡片模式**：视口小于 1024px 时数据列表的呈现形态，同一套列表配置（列、筛选、排序、权限）自动生效，各业务页面无需单独适配。术语唯一定义见 CONTEXT.md。
- **移动端功能边界**：移动端只做浏览/搜索/筛选/详情/行内轻操作；重录入与批量类重操作回桌面，属有意切割而非缺失。

## 功能清单

### 卡片列表

- 列表页在小屏下自动从表格切换为卡片流；窗口拖回宽屏即时恢复表格，搜索/筛选/排序条件保留。
- 卡片内容按约定取自列表列：默认第 1 列为标题（如单号）、第 2 列为副标题（如客户名）、其后至多 3 列为摘要（状态以胶囊、日期本地化、金额右对齐等，与表格口径一致）。桌面列序为公司首列/筛选用时，各页用 `mobileRole` 重排卡片字段——**条目表**以物料为标题、对手为副标题、状态与数量/金额为摘要；**单据头**以单号为标题、对手为副标题；公司列与对手类型等在卡片上隐藏但仍可筛选。
- 点卡片打开详情抽屉（小屏全屏）；点卡片上的 ⋯ 菜单执行该行动作（查看/审批/确认/作废等，按权限与单据状态显隐，与桌面一致）。
- 翻页为列表底部「加载更多」按钮（显示已加载/总数）；条件变更后从头重新加载；已加载全部时给出终点提示。

### 搜索、筛选与排序

- 搜索框常驻列表顶部，与桌面同一搜索。
- 「筛选」按钮（带已生效条件计数）打开底部筛选弹层，按列配置条件（枚举勾选、数值区间、日期范围、往来单位选择等，与桌面列头筛选等价）；已生效条件以 Chips 形式列于列表上方，可逐个清除或清除全部。
- 「排序」按钮打开底部排序弹层，点按列在 升序→降序→取消 间循环；与桌面表头排序是同一份状态，两侧互见。树形列表（物料分类等）不提供排序入口（同桌面）。

### 树形列表

- 树形资源（物料分类等）在移动端不做逐层展开，常驻为平铺卡片，找节点靠搜索。

### 图片与附件

- 图片列与图片附件列在卡片上以缩略图呈现，点开全屏预览（缩放/旋转/下载/循环切换），与桌面一致。

### 选择器

- 弹窗选记录（选择器）在移动端同样为卡片：单选点卡片即选，多选卡片勾选，翻页追加时已选保留。

### 移动端功能边界

- 不出现：新增/编辑入口、导入、导出、打印、勾选批量操作（默认）。有移动端价值的特定动作可由页面显式放上来（如移动审批），不适合手机的动作可显式拿下（如行内打印）。
- 建单与录入（含子条目编辑表格）在移动端维持桌面表格形态，不在本期适配范围。

## 业务流程

无独立流程；移动端是全部业务列表的统一呈现形态，业务规则（状态机、权限、校验）与桌面完全一致。
