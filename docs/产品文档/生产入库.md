# 生产入库

## 概述

生产入库是对生产工单的**成品入账**单据。仓管建草稿、挂工单与叶子仓、分次录入；审核写正向库存分录并累加工单已入数量，作废回滚。对齐采购入库/销售发货的分次与容差模型。

边界：第一期只数量账、不过生产成本总账；不做副产品行、不扣原料、无 WIP 仓。

## 核心概念

- **生产入库单**：草稿 → 已审核 → 已作废；仅草稿可改可删；无反审核。
- **生产入库条目**（亦称生产入库行）：必挂生产工单，物料须与工单一致；单位/数量折算默认单位；行仓为本公司启用叶子仓。见 [术语表](../../CONTEXT.md)。
- **生产入库超入比例**：生产设置中的全局容差（0～1，默认 0）；审核时累计已入 ≤ 工单数量 × (1 + 比例)。见 [术语表](../../CONTEXT.md)。

## 功能清单

### 列表视图

- 双 tab：**入库条目**（默认）与**入库单**；共用生产入库单抽屉。
- **入库条目** tab 展示行快照口径的物料信息、生产工单、入库仓库，以及母单号/日期/状态（列表 join 投影）。
- **入库条目** tab 可直接「新建入库单」（与入库单 tab 同一抽屉表单）；草稿单条目提供行操作「审核整单」，与入库单 tab 的「审核」一样先弹出整单条目核对确认框，确认后才审核。删除与作废只在入库单 tab。
- 菜单：供应链 → 生产 → 生产入库。

### 录入与审核

- 头：公司、入库日期、可选默认仓、备注；单号可留空自动取号。
- 行（入库条目）：工单（弹窗选择）、数量、单位、仓库；物料由工单带出，单位锁定工单单位（选工单带入、不可手改）；行号系统自动分配。
- 行数量输入框尾部提示工单**当前未入**（已审核入库累计后的剩余，折回工单行单位；不含本单草稿）。选工单弹窗展示入库进度列。
- 一单可多行挂不同工单；同一工单可被多张入库单分次入。
- 审核：硬拦超入；写正向库存分录（来源类型生产入库）；累加工单已入；满量或容差内超入后工单完工并回写需求行已完成。
- 草稿不硬卡超入。

### 作废

- 仅已审核可作废：库存分录标记作废（过负库存校验）+ 回滚已入；若因此未完成回升则工单回进行中、需求行回已安排（仍有工单时）。
- 有已审核未作废入库时不可作废工单。

### 生产设置

- 菜单「供应链 → 供应链设置 → 生产」Tab 维护超入比例（独立权限资源 `mfg.setting`）。

### 权限

- 独立权限（默认仓管）；与需求单、工单分权。

## 业务流程

1. 工单进行中 → 建生产入库草稿 → 挂工单与仓 → 审核。
2. 库存增加、工单进度更新；满量自动完工。
3. 录错可作废已审核单（库存与进度回滚）。
