# 模具设计

## 概述

模具设计是生产域的模具档案：每一套模具在此建档，系统自动为其创建一个对应的**资产类物料**（一一对应），模具因此天然进入物料编号体系与采购付款流程（采购入库不写库存分录、不参与库存数量账）。菜单入口「生产管理 → 模具管理」。

## 核心概念

- **模具设计**：一套模具的档案记录，与物料一一对应；自身只记录**模具类型**，名称/规格/单位由对应物料承载。
- **模具类型**：模具的工艺分类——**冲压 / 变形 / 定位 / 其他**，必选。
- **模具物料分类**：生产设置中的全局配置——建模具时自动创建的物料归入该分类；未配置时不能建模具。须为启用的叶子分类，建议在「E 设备工量具」大类下自建模具叶子分类。
- **模具编号**：自动创建物料时按物料编号规则取号（分类号-序号），不接受手填、创建后不可改。

## 功能清单

### 前置配置

- 在「生产管理 → 生产设置」中配置**模具物料分类**（选择启用的叶子物料分类）。
- 未配置时在模具管理页新建模具会提示先去配置，保存不生效。

### 模具新建与编辑

- 新建模具只需填写：**模具名称**（必填）、**模具规格**（选填）、**模具类型**（必选）、**单位**（必选）；**图纸**（仅图片、可多张）与**附件**（不限类型）可随建随传。
- 保存时系统自动创建对应物料（资产类型、归入设置的模具物料分类、自动编号、默认启用）并与之绑定，一步完成，无需先建物料。
- 编辑可改名称/规格/模具类型/单位，改动同步到对应物料；该物料已有单位转换行时单位不可改（先删除转换行）。
- 模具档案全局共享、不分公司；操作留审计记录（模具与物料双双留痕）。

### 模具删除

- 删除模具会一并删除其对应的物料（含单位转换行）。
- 物料已被库存分录或业务单据引用的模具不可删除；删除即彻底删除，无归档。

### 模具列表浏览

- 入口：「生产管理 → 模具管理」页面，全局共享无公司选择器。
- 模具编号、名称、规格、模具类型、单位、创建时间均可筛可排。
- 增删改查需具备模具设计的相应权限，操作接审计。

## 边界

- 模具不与生产工单/BOM 联动，不跟踪模次与寿命。
- 资产卡片、折旧、转移、维修、处置等完整资产管理未实现。
- 模具对应物料按资产类物料的单据准入规则流转：可采购（采购报价/订单/入库，入库审核不写库存分录），不进销售侧单据、库存单据、委外与 BOM（详见 [库存物料](./库存物料.md)「物料类型与单据准入」）。
