# 生产工单

## 概述

生产工单是自制执行的**未完成数量容器**：车间主任从已确认、履约方式=自制、尚无未作废工单的需求行生成；一需求行至多一张未作废工单。工单不存客户、不挂销售单价；列表展示物料、数量、需求日、来源需求单与未完成数量。

边界：第一期不建工序报工、工艺纸条数字化、有限产能排产；完工事实来自生产入库，不靠报工点完成。

## 核心概念

- **生产工单**：公司 + 物料 + 数量 + 交期/需求日 + 来源需求行；状态 进行中 → 已完工，或作废。见 [术语表](../../CONTEXT.md)。
- **未完成数量**：工单数量（默认单位）− 累计生产入库；容差内超入可为负显示。

## 功能清单

### 生成

- 前置：需求单已确认、行自制、行未完成、无未作废工单。
- 新增工单时，「来源需求行」使用 dialog 弹窗表格选择器，支持搜索、筛选后单选带入；桌面列按「公司 → 需求单 → 行号 → 物料信息 → 数量/单位 → 需求日 → 履约方式 → 状态」排列，隐藏折算量、系统投影、内部外键、销售来源与时间戳，初始按需求日升序；移动端卡片只保留物料名称、需求单、数量、需求日与状态。
- 选定来源需求行后，系统自动带入公司、来源需求单、物料、单位、需求日、数量口径及物料/单位快照；这些字段均为只读派生信息，用户只需填写可空的工单号，无需重复选择。
- 数量与物料锁定为需求行口径；单号可留空自动取号。
- 生成后需求行状态 → 已安排。

### 作废

- 仅进行中、且无已审核未作废生产入库时可作废。
- 作废后需求行回待安排，可再生成。

### 完工

- 累计生产入库 ≥ 工单数量时系统标已完工，并回写需求行已完成（见生产入库）。

### 权限

- 独立权限（车间侧）；无销售订单/客户权限时不应依赖客户字段（工单本身不存客户）。

## 业务流程

1. 计划确认自制需求行。
2. 车间主任生成工单。
3. 仓管分次生产入库；满量后工单与需求行自动完成。
