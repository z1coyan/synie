# 生产工单

## 概述

生产工单是自制执行的**未完成数量容器**：车间从已确认未关闭的履约需求行生成；**必挂来源需求行**，同一需求行可并行多张未作废工单；数量可手填（默认剩余可安排）。工单不存客户、不挂销售单价；可选 BOM（快照）、带入物料图纸。

边界：本期不建工序报工、有限产能排产、按 BOM 快照实扣料；完工事实来自生产入库。

## 核心概念

- **生产工单**：公司 + 物料 + 数量 + 交期/需求日 + 来源需求行 + 可选 BOM 快照 + 图纸挂接；状态 进行中 → 已完工，或作废。见 [术语表](../../CONTEXT.md)。
- **未完成数量**：工单数量（默认单位）− 累计生产入库；容差内超入可为负显示。
- **已安排**：创建工单即向来源需求行倒写**生产**安排并占已安排数量；作废释放。
- **归属部门**：创建时按创建人部门自动盖章，不可手填；创建人无部门即为空。

## 功能清单

### 生成

- 前置：需求单已确认未关闭、行未整单禁止新安排、本笔数量过需求超安排比例。
- 新增时「来源需求行」用 dialog 表格选择器；选定后公司、来源需求单、物料、单位、需求日及物料/单位快照只读带入。
- **数量**默认可编辑为剩余可安排（不含容差超额），可手改，须过超安排比例。
- 创建时复制物料 `drawing` 图纸挂接到工单（无图不拦）。
- 单号可留空自动取号。

### BOM（可选）

- 可空；限选本物料**启用中** BOM。
- 选后快照配料 / 工艺路线 / 副产品到工单私有子表，与主数据脱钩。
- 尚无已审核生产入库前：可换选、手改快照行、清空 BOM；有入库后锁死。
- 手改快照不回写 BOM 主数据。
- **工单内快速创建 BOM**：嵌套完整 BOM 创建能力（母物料锁=工单物料），保存即建正式 BOM 并选入快照。

### 列表

- 「入库进度」合并列：进度条 + 百分比单行展示，点击弹出数量明细（工单数量 / 已入库 / 未完成，折回行单位）；该列筛选与排序即**未完成数量**口径。
- 物料编码并入物料名称一格展示；搜索框可命中工单号、物料编码 / 名称 / 规格。

### 改数量 / 作废

- 仅进行中且无已审核未作废生产入库时可改数量或作废。
- 作废后释放需求行已安排，可再开新工单。
- 作废/删除同时级联清理本工单派生的需求单草稿（见「生成物料需求」）。

### 生成物料需求

- 进行中工单的行动作：按 BOM 快照展开配料，逐行显示**毛需求**、**参考库存**与**净需求**，逐行（可批量）选定去向——某车间 / 采购 / 不需要——一次提交按去向分组生成多张履约需求单**草稿**（每个目标车间一张、头已填下发车间；采购向一张、下发为空）。派生规则与来源工单链接见 [履约需求](./履约需求.md)「工单派生」。
- **毛需求** = 配料净用量 ×（1 + 损耗率，空按 1）× 工单数量，即 BOM 的「理论耗用」口径。
- **参考库存** = 本公司全部仓库现货合计（折算行单位），仅是打开弹窗瞬间的只读快照——不锁库、不扣减、不预留；生成后库存变动不回溯已生成草稿。
- **净需求**默认 = 毛需求 − 参考库存（下限 0），可手改（允许大于毛需求）；参考库存足够的行默认去向「不需要」。
- 可用条件：工单进行中且已挂 BOM 快照——无快照配料行时明确报错「工单未挂 BOM 快照，无法生成物料需求」；已完工/已作废不可执行。
- 重复生成：已有未删除的派生草稿时先提示已有草稿单号，二次确认后才真正再生成。
- 工单作废/删除：级联删除仍未确认的派生草稿；存在已确认派生单时响应带单号警告名单但不拦截。改工单数量不回溯已派生草稿。

### 完工

- 累计生产入库 ≥ 工单数量时系统标已完工，并累加需求行已完成数量（见生产入库）。

### 打印

- 支持单条与**批量**模板打印 / 导出 Excel（权限 `mfg.work_order:print` / `batch_print` / `export`）。
- 模板资源码 `mfg.work_order`；可占位头字段（工单号、数量、物料快照、公司、来源需求单、BOM 等）及循环区配料 / 工艺路线 / 副产品快照。
- 模板在「系统管理 → 打印模板」维护；无模板时操作会提示先上传。

### 权限

- 独立权限（车间侧）；工单不存客户字段。
- 车间角色按「本部门」数据范围只看归属本部门的工单；建单同时要求来源需求单可读（即已下发到本车间）。
- 车间角色持「生成物料需求」动作权限，经该入口自助派生并自审需求单；需求单侧仍不授创建（手工建单/销售勾选保持关闭，见 [履约需求](./履约需求.md)）。

## 业务流程

1. 计划确认需求行（可与其它安排混排）。
2. 车间开一张或多张工单（可带 BOM/图纸）。
3. 仓管分次生产入库；满量后工单完工，需求行按已安排/已完成双投影判定完成。
