# 销售发货

## 概述

销售发货模块承载对客户/内部公司的**履约出库**：从已审核销售订单条目分批发货，审核后扣减库存、累加订单已发数量，有金额时按头上借贷科目确认未开票应收。服务销售内勤与仓管。

边界：不做存货成本/销项税拆分（税在发票、成本待采购估值）；内部公司对手只记卖方账，不自动镜像买方入库；无反审核/红冲；发货与发票的勾稽由销售对账单承载（见 [销售对账](./销售对账.md)）。

## 核心概念

- **销售发货单**：履约出库单据，状态机 草稿→已审核→（已作废）。见 [术语表](../../CONTEXT.md)。
- **发货条目**：必挂订单条目；行仓必填；数量折默认单位；行保存冻物料与订单条目快照（含图纸挂接复制）。
- **已发数量**：订单条目上默认单位累计，审核加、作废减。
- **已对账数量**：发货条目上默认单位累计，由生效中的销售对账单同步（确认/结单加、撤回/作废减）；剩余可对账 = 发货数量 − 已对账数量。见 [销售对账](./销售对账.md)。
- **发货超发比例**：供应链设置全局容差，默认 0%（禁超发）；入口「销售管理 → 销售设置」。
- **公司默认过账科目（发货）**：按公司可配发货借/贷默认值；入口同上销售 Tab（先选公司再编）。见 [术语表](../../CONTEXT.md)。
- **物料快照**：行保存时冻结编号/名称/规格/客户料号/单位名，并把物料当前图纸（`drawing` 槽位）挂接复制到行；审核锁行即冻结，主数据后续变更不回溯。图纸为挂接复制（共享不可变文件，非字节复制），行/发货单删除时挂接一并清理。口径与订单条目快照一致，见 [术语表](../../CONTEXT.md)。
- **装箱清单**：发货单下可选的装箱明细——**装箱箱**（箱号＋箱净重＋箱毛重＋重量单位）与**装箱行**（所属箱＋物料＋单位＋数量＋行净重＋行备注）两级，随货箱单的系统记录处；纯实物复核层，不落库存/总账，无账面后果。见 [术语表](../../CONTEXT.md)。
- **行净重 / 箱净重 / 箱毛重**：行净重＝该行物料总净重，默认按数量×重量换算推导、可手改实测，数量变化即重算（有推导来源时）；箱净重＝Σ 行净重折算（只读）；箱毛重＝整箱过磅手填。不建皮重；重量可空、审核不拦；实测值不回写物料换算。见 [术语表](../../CONTEXT.md)。

## 功能清单

### 列表视图

- 双 tab：**发货条目**（默认）与**发货单**；共用发货单抽屉。
- **发货条目** tab 展示行快照口径的物料信息，另有图纸列（缩略图，点开可预览该行全部图纸）。
- **发货条目** tab 可直接「新建发货单」（与发货单 tab 同一抽屉表单）；草稿单条目提供行操作「审核整单」，与发货单 tab 的「审核」一样先弹出整单条目核对确认框，确认后才审核。
- 菜单：销售管理 → 交易 → 销售发货。

### 发货录入

- 抽屉分两个 tab：**发货信息**（默认，头字段＋发货条目＋表底借贷科目）与**装箱清单**（装箱行独占，标签带行数徽标）；查看/编辑/新建三态同构。
- **整单草稿保存**：一次保存覆盖表头、发货条目、装箱箱及其装箱行；只有全部内容都有效时才会保存。任一字段、条目、箱或装箱行有误，整张草稿都保持保存前状态，抽屉保留输入并定位到对应字段或行，不存在部分保存成功。
- **完整状态替换**：编辑保存以抽屉中的全部当前内容为准；保留的内容继续存在，新内容由系统建立，已移除的发货条目、装箱箱或装箱行随保存删除（删箱一并删除箱内装箱行）。引用未知、重复或属于其他发货单的既有内容时，整单保存会被拒绝。完整发货条目与装箱子树加载完成前保存入口不可用，加载失败不会把暂态空表解释为删除全部子记录。
- 头（表头区）：公司（建后不可换）、发货单号（可留空取号）、发货日期、过账日期、对手（客户/内部公司）、默认仓库（可空，新建行预填）、备注。
- 行：订单条目（须已审核订单）、数量、单位（可空=订单单位）、出库仓库（必填）、行备注；保存时同步冻结物料快照与图纸挂接。
- 表底（低于条目表）：借方科目（未开票应收角色）、贷方科目——**草稿保存即必填**；新建或换公司时按该公司默认过账科目整组覆盖代入（无默认则清空）；打开已有草稿且未改公司则保留单上科目。
- 可跨多张订单，但公司、对手、原币须一致。
- 发货条目工具栏另有**「从装箱清单获取」**按钮（见下节），支持先录装箱再一键补齐发货条目的逆向动线。

### 审核

- 有审核权限的用户在抽屉表单保存时可选「保存并审核」；系统先原子保存完整草稿，保存成功后再发起独立审核。保存失败不审核；审核失败不回滚已保存草稿，抽屉保留可编辑状态供修正后重试。
- 至少一行；行仓须本公司启用叶子仓。
- 超发校验：累计已发 ≤ 订购 base × (1 + 超发比例)。
- 装箱校验（全有或全无）：填了装箱清单的发货单，按物料汇总比对「装箱量＝发货量」逐物料相等——漏装任一物料、任一物料不等、含发货外物料，均拒审并点名物料与两侧数量（默认单位口径，报错带默认单位名）；整表不填则照常审核；草稿保存不校验（同超发容差先例）。
- 写负向库存分录；有金额时写总账两行（借未开票应收、贷选定科目）；累加已发数量。
- 整单金额为零：跳过总账（不造名义分录），但头上借贷科目仍须已填。

### 装箱清单

- 发货单抽屉「装箱清单」tab 的可选编辑区，箱/行两级交互：**「添加箱子」**建箱（箱号系统按单内自增整数生成，不可手改；删除箱级联删除其装箱行），箱上维护**箱毛重**（手填，整箱过磅）与**重量单位**（限重量类，默认基准单位，可改），**箱净重**＝Σ 箱内行净重折算、只读；箱内**「添加物料」**增装箱行（同箱多物料在表格中按箱合并显示）——行＝物料（候选＝**可发货订单条目池**去重物料，与订单条目选择弹窗同口径：同公司同对手、订单已审核、未发数量>0）＋单位（限该物料默认单位或转换单位，录入时实时折算展示默认单位数量，保存由系统重拍）＋数量（>0）＋**行净重**＋行备注。
- **行净重**：该行物料总净重。默认按「行数量 × 重量换算」推导——行单位本身是重量类则直接用行换算；否则物料恰有一条重量类单位转换行则经它折算；有多条重量转换行则不猜、默认空手填。可手改为实测值；有推导来源时数量/单位/物料变化即无条件重算（实测手改应在数量定稿后录入），无来源时手填值不动。行净重单位随推导来源或重量基准单位、不可手改。落库随审核冻结，**不回写物料换算**（建/改换算去物料主数据维护）。
- **可先装箱后补条目**：装箱行不依赖本单发货条目，选齐公司与对手即可录箱录行——现场先装箱、单证后补的动线在系统内成立。
- 一物料可拆多箱（分挂多箱多行）；行保存冻结物料快照（编号/名称/规格/客户料号/单位名，不复制图纸挂接），主数据后改不回溯。
- 重量全部可空、审核不拦（无「毛重 ≥ 净重」硬校验）；整表可不填；填了则审核时按上方「审核」节的全有或全无口径硬校验数量。
- 随发货单级联删除、审核后随单锁死；不落库存/总账，不进收发货历史、不进列表 tab 与 CSV 导出。
- 权限随销售发货各动作，不新增权限点；装箱行仍以 `pack_lines` 平铺循环区进入打印字段目录（箱字段经 belongs_to 箱一层展开，如 `${pack_lines.box_gross_weight}`），另增 `pack_boxes` 独立循环区（箱号/箱净重/箱毛重/重量单位），箱单按公司版式经打印模板输出（见 [系统管理](./系统管理.md) 打印模板）。

### 从装箱清单获取

发货条目工具栏按钮（无装箱行时禁用并提示先录装箱；头默认仓库为空时点击拦截提示先填），把装箱事实一键转成发货条目草稿：

- **增量补齐**：只处理还没有发货条目的物料；已有条目的物料一律不动。
- **FIFO 分摊**：按物料汇总装箱量（折默认单位），候选条目按订单日期升序（同单按订单号、条目 id 兜底）依次扣未发数量，装满一条扣下一条，一物料可拆多行。
- **币种锁定**：全部行订单原币须一致的既有约束下——已有条目则以现有行币种锁候选池，空条目则以全部候选中订单日期最早者的币种定整单；异币种候选排除并报出。
- **尾差只分不超**：装箱量超全部候选未发合计时只足额分配，余量不压进任何订单条目（超发与否是业务决定），报进结果由用户手工补行或改装箱。
- **生成行**：订单条目＝FIFO 命中条目，单位随订单条目锁定，数量＝分摊 base × 单位换算系数的精确值（服务端重算 base 与装箱汇总分毫不差，审核装箱等式不受损），出库仓库统一预填头默认仓；生成即普通草稿行，可改可删，随单保存落库。
- **结果反馈两档**：全部顺利时 sonner 一句话（已生成 N 行）；有任何注意项则弹框分三组列明——①已生成明细（物料→订单→数量）②未分配（尾差/零候选/币种不符，审核前必须人工处理）③已有条目与装箱对不上（仅提醒，数据未改动）。

### 作废

- 仅已审核可作废：库存/总账分录作废，回滚已发数量（过负库存校验）。
- 任一条目存在非零已对账数量（被生效中销售对账单消耗）则整单不可作废，须先撤回/作废相关对账单。

### 与订单交叉

- 关闭订单后不可再发；有已审核发货时订单不可作废；草稿发货须先删再作废订单。

## 业务流程

录入草稿 → 审核算库存与应收 → 纠错作废重开。订单部分发完可关闭剩余。
