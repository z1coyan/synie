# 采购订单

## 概述

采购订单模块承载公司与供应商之间的订货承诺：录入公司要买的物料、数量与含税价格，审核后单据生效锁死，作为将来入库与收票的源头依据。服务采购内勤与跟单人员。

边界：订单是纯业务承诺——审核不派生任何会计或库存后果。实物入库、未开票应付过账与订单已收数量由**采购入库单**承载（见 [采购入库](./采购入库.md)）；入库与进项发票的勾稽由采购对账承载（见 [采购对账](./采购对账.md)）。勾选委外标记的**委外订单**走委外执行链：材料发出由**委外发料单**承载（见 [委外发料](./委外发料.md)），成品回收、外协材料扣减与副产物回收由**委外入库单**承载（见 [委外入库](./委外入库.md)）。

## 核心概念

- **采购订单**：公司向供应商承诺采购的订货单据，状态机 草稿→已审核→（已关闭/已作废）。见 [术语表](../../CONTEXT.md)。
- **订单类型**：订单分**常规订单**与**零星订单**两类，新建必选，保存后不可改（换类型只能作废重开）。两类共用状态机、编号规则与权限。
- **常规订单**：条目只能从**有效采购报价条目**里逐行挑选——报价单已审核、订单日期落在报价有效期内、公司/对手/币种均一致。单价与单位随报价锁定（固定价直接带入；数量梯度按行数量自动套档，低于首档起订量视为无报价无法保存），改价必须重报价；仅税率带入后可手改。
- **零星订单**：条目任选物料、手填单价（即无报价约束），但单行数量不得超过供应链设置中的零星上限（默认 100，按行录入数量直接比较，不做单位换算）。
- **订单条目**：订单的商品行，记录物料、单位、数量、原币含税单价、税率；金额列全部由系统按金额链计算（见下）。常规订单行必带报价条目引用，零星订单行必不带。条目可空挂**来源履约需求行**（从需求单勾选带入，见下）与可空**需求日**（带入自需求行，纯展示不驱动逻辑）。
- **币种与汇率（双币）**：一单一币——币种（原币）与汇率挂订单头，新建默认取单据公司本币，全部条目跟随换算；本币单汇率强制为 1（界面不出汇率字段），外币单汇率必填（大于零，手工填写，无汇率牌价表）。金额链：原币金额=数量×原币单价（2 位）→ 本币金额=原币金额×汇率（2 位）；本币单价=原币单价×汇率（4 位）仅展示参考。落库统一双套（本币单两套同值），报表口径一律读本币列。口径与销售订单一致，见 [术语表](../../CONTEXT.md)。
- **订单条目快照**：行保存（新增/修改）时把物料编号/名称/规格/客户料号与单位名称冻结到行上，并把物料当前图纸（`drawing` 槽位文件）复制挂接到行；审核锁行即冻结，主数据后续变更不回溯，订单上下文展示一律以快照为准。图纸为挂接复制（共享不可变文件，非字节复制），行/订单删除时挂接一并清理。机制与销售订单一致，见 [术语表](../../CONTEXT.md)。
- **对手**：订单的供应商方，取供应商主数据或内部公司（多态引用）。
- **含税总额**：订单全部条目含税金额的合计（原币/本币各一列），随行自动算出，只读。
- **委外标记**：订单头布尔标记，勾选即**委外订单**——条目＝委外加工回来的成品、条目含税单价＝加工费单价；新建期可勾选，保存后锁死（换标记只能删草稿/作废重开）。与订单类型正交：常规委外条目照常强制有效采购报价引用（供应商对成品的报价即加工费报价），零星委外手填加工费；状态机、双币金额链、关闭/作废规则与普通采购订单一致。见 [术语表](../../CONTEXT.md)。
- **成品 BOM 引用**：委外订单条目上可空的 BOM 引用，限选条目物料自身的 BOM，仅作「按哪张配方发料」的来源留痕；BOM 删除时条目上的引用自动清空。见 [生产BOM](./生产BOM.md)。
- **发料清单**：委外订单条目下「需发给协作方的材料」子表（材料＋单位＋数量＋行备注），随条目级联删除；行上另有只读的**已发料量**（材料默认单位口径），由委外发料审核加、作废减，剩余可发＝清单数量−已发料量，超发不硬拦、超额仅展示。是委外发料单的唯一取行来源，见 [委外发料](./委外发料.md)。
- **副产物清单**：委外订单条目下「预期随成品一起回来的副产物」子表（材料＋单位＋数量＋行备注），随条目级联删除；是委外入库副产物行的带出来源，见 [委外入库](./委外入库.md)。

## 功能清单

### 列表视图

- 页面分两个 tab（子路由，URL 可直达）：**订单条目**（默认视图，行级明细——每行展示所属订单号、订单日期、对手、订单状态，以及行快照口径的物料编号/名称/规格、单位、收货进度、币种、本币单价、原币单价、本币金额、原币金额、行备注，另有图纸列（缩略图，点开可预览该行全部图纸）；其中**收货进度**为数量/已收/未收三合为一列：进度条＋「已收/数量、未收」按行单位展示（已收/未收存储为物料默认单位口径，展示按行单位换算比折回），该列的筛选与排序均按**未收数量**口径；跨订单混合行恒展示双币全列（本币单两套同值）；默认按订单日期倒序；点订单号或行「查看」开完整订单抽屉，草稿单可经行「编辑」直接改单）与**订单**（整单列表，含币种、原币/本币含税总额列与审核/关闭/作废/删除动作）。
- 两个 tab 共用同一个订单抽屉（新增/查看/编辑三态），「新建订单」入口两个 tab 都有（条目 tab 直接新建整单，与订单 tab 同一表单）；关闭/作废/删除只在订单 tab。
- 订单抽屉分两个标签页：**基本信息**（订单头字段＋条目表＋交易条款，即原单页内容）与**收货历史**（该订单全部入库单行，只读——入库单号、入库日期、入库状态、物料快照、单位、数量，按入库日期倒序；采购入库行与**委外入库**行同 tab 分组列出；新建未保存时显示提示，无收货记录显示空态）。
- 菜单：供应链 → 交易 → 采购订单。

### 订单录入

- 头：订单类型（常规/零星，必选，保存后不可改）、**委外标记**（勾选即委外订单，保存后不可改）、订单号、订单日期（默认当天）、公司、对手、币种、汇率（仅外币单）、交易条款（对供应商，自由多行文本）、订单备注（对内）。
- 订单号留空按编号规则自动取号，手填原样保留；订单号全局唯一；两类订单共用同一编号规则（想区分单号可在编号规则里加订单类型字段段）。
- 对手限供应商/内部公司两类；选内部公司时不能是订单所属公司自身。
- 币种：选公司后自动带出公司本币，可手动改为外币；选本币时汇率字段隐藏（系统固定为 1），选外币时汇率必填且大于零。草稿期间改币种/汇率，全部条目的本币金额随之重算；审核后随单冻结。
- 条目子表在订单类型、对手、公司、订单日期选齐之前不可新增；上述四项或币种任一变更加载即清空已录条目（类型保存后锁定，仅新建期可改）。
- 常规订单条目行：从有效采购报价条目选择器逐行挑选（仅列已审核、订单日期在报价有效期内、公司/对手/币种一致的报价条目，可跨多张报价单）；选定后物料、单位、含税单价由报价带入且锁定——数量梯度条目按行数量自动套档，低于首档起订量保存报错；税率从报价带入默认，可手改；另可填行备注。
- 零星订单条目行：物料、单位、数量、原币含税单价、税率、行备注自由录入；单位只能选该物料的默认单位或其单位转换单位，选物料后默认带默认单位；单行数量不得超过供应链设置的零星上限（默认 100）。采购侧不校验客户物料约束，任何物料均可录入。
- 常规订单条目经报价带出的物料在报价侧已无选料约束；行保存与审核仍复核物料与报价引用一致。
- 条目约束：数量必须大于零；原币含税单价可为零（赠品）；税率必填，界面按百分比录入（默认 13%，存储为小数 0.13）；金额列（原币金额、本币金额、本币单价）由系统按金额链计算，不可手改。
- 条目展示随整单币种简化：整单本币时只显示一套「含税单价/含税金额」；外币单展开双套列并在行表单给出本币含税金额只读预览。

### 从履约需求单勾选带入

- 条目编辑区提供「从需求单勾选」入口：勾选**已确认（未关闭、未作废）**履约需求单上、未完成、剩余可下单量 > 0、公司与订单一致的需求行，带入生成条目；一条目挂一需求行，同一需求行可分次被多张订单引用。
- **履约方式严格匹配**：普通采购订单只能勾「外购」行，委外订单只能勾「委外」行；方式不对须回需求行改履约方式。
- 带入落：物料、数量（默认=剩余可下单量，可改）、需求日、来源需求行引用；价格机制原样（常规行照常勾有效报价、零星行照常手填单价）。委外订单带入不自动代 BOM/发料清单/副产物清单，走现有手选代入机制。
- 勾选池查询挂采购订单自身权限，只暴露带入所需字段；采购员无需需求单读权限。手工录入的行不带需求来源，两者并存。
- **草稿不占量**：需求行「已下单数量」投影只认已审核未作废订单（审核加、作废减）；订单**审核时复核**——来源需求行存在、所属单已确认未作废未关闭、行未完成、履约方式匹配、且累计已下单（含本单）≤ 需求数量 × (1 + **需求超下单比例**)，任一不过拒绝审核。
- 已审核未作废订单引用的需求行：需求单不可作废、该行不可改履约方式（草稿订单引用不构成约束）。

### 条目委外配置（仅委外订单）

委外订单的条目行抽屉内多出委外配置区：**成品 BOM** 引用与**发料清单**、**副产物清单**两个子表。全部可选——不配 BOM/清单不挡开单与审核（条目无发料清单则委外发料无行可挂、自然卡住）。

- **成品 BOM**：可空，选择器只列条目物料自身的 BOM（以编号为主、方案名称辅助区分同物料多张）；仅作来源留痕，BOM 后续变更不回溯本单，BOM 删除时引用自动清空。
- **从 BOM 代入**：选定 BOM 后按当前条目数量折算代入两清单——发料清单按 理论耗用＝净用量×（1＋损耗率，空按 0）×条目数量，副产物清单按 单位产出量×条目数量。代入是**快照复制**：代入后与 BOM 脱钩、可自由增删改；改条目数量不自动重算（要重算＝清空清单再代入一次）。
- 两清单行＝材料＋单位（限该材料默认单位或其转换单位）＋数量（大于零）＋行备注；随条目一并保存、随条目级联删除；仅草稿订单可编辑。
- 发料清单行带只读**已发料量**（材料默认单位口径），由委外发料单审核累加、作废扣减，见 [委外发料](./委外发料.md)。
- 查看态条目提供「委外配置」只读弹窗，展示该行的 BOM 与两清单。

### 审核

- 仅草稿单可审核；审核前必须至少有一行条目（其余字段约束在录入期已强制）。
- 审核入口：订单 tab 行「审核」与条目 tab 行「审核整单」都会先弹出整单条目核对确认框（列出该单全部条目），确认后才提交审核；有审核权限的用户在订单抽屉也可直接「保存并审核」（保存成功紧接着审核同一单）。
- 审核时逐行复核：常规订单校验每行报价引用仍有效（已审核、在有效期、公司/对手/币种一致）且单价与报价一致；零星订单校验每行数量不超过当前供应链设置的零星上限；挂来源需求行的行复核需求行仍有效并校验超下单容差（见「从履约需求单勾选带入」）。
- 审核同一事务累加来源需求行的**已下单数量**投影（作废回滚）。
- 审核后单据锁死：头不可改、行不可增删改、单不可删；无反审核。

### 关闭与作废

- 仅已审核单可关闭或作废，两者都是终态、不可逆。
- 作废：单据不该存在（录入错误、未履行即取消）。存在已审核未作废入库（采购入库或委外入库）引用其条目时订单不可作废，须先作废相关入库单；存在草稿入库引用时须先删除相关草稿入库单。
- 关闭：单据生效过但提前终止或执行完毕，人工标记不再履行。已关闭订单不可再入库（含委外入库）与委外发料。

### 删除

- 仅草稿单可删除，条目随单一并删除。

### 供应链设置（采购 Tab）

入口：「供应链 → 设置 → 采购」。采侧配置分两层——**全局标量**（`sal_setting`，非公司维度）与**按公司默认过账科目**（独立资源；销售项见销售 Tab）：

- **零星订单单行数量上限**（默认 100）：零星订单单个条目的数量不得超过该值，按行录入数量直接比较、不做单位换算；常规订单不受此限。改小不追溯存量草稿，在条目保存与订单审核时校验。
- **入库超收比例**（默认 0%）：入库审核时允许累计已收 ≤ 订购数量 × (1 + 比例)；0% 表示禁止超收。细节见 [采购入库](./采购入库.md)。
- **需求超下单比例**（默认 0%）：采购/委外订单审核时允许来源需求行累计已下单 ≤ 需求数量 × (1 + 比例)；0% 表示禁止超下单；草稿不硬卡、审核硬拦。细节见「从履约需求单勾选带入」。
- **采购入库默认科目**（按公司，可空）：先选公司，再配入库借方/贷方（未开票应付角色）默认值；新建或换公司入库单时整组覆盖代入。细节见 [采购入库](./采购入库.md)。

## 业务流程

录入（草稿，可反复改）→ 审核（生效锁死）→ 执行完毕或提前终止时点「关闭」；发现单据错误则在审核后直接「作废」，草稿阶段直接删除。变更已审核单没有改单动线，作废/关闭后重新开单。
