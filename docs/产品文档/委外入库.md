# 委外入库

## 概述

委外入库模块承载委外加工链路的**成品回收**：登记协作方加工完成送回的成品（行必挂委外订单条目），审核时同一事务完成三件事——成品入本公司仓、按消耗从外协仓扣减材料、副产物入本公司仓，同时累加订单条目已收数量，有加工费金额时按头上借贷科目确认未开票应付（财务行为完整镜像采购入库）。服务仓管与会计。

边界：材料扣减与副产物入库只记数量、不产生金额（材料物化进成品的成本与副产物估值随库存金额账一并设计）；无反审核/红冲；内部公司对手只记我方账，不自动镜像对方出库；加工费与进项发票的勾稽由采购对账承载（委外入库行进采购对账条目池，见 [采购对账](./采购对账.md)）。

## 核心概念

- **委外入库单**：委外成品回库的履约入库单据，状态机 草稿→已审核→（已作废）。见 [术语表](../../CONTEXT.md)。
- **入库条目**（成品行）：必挂已审核委外订单条目，物料须与条目一致；行保存冻结物料快照与订单条目快照（订单号、订购量、加工费价税、本币金额、税率、币种代码等）。
- **材料扣减行**：挂在入库条目下的子行，必挂同一条目的发料清单行；审核写外协仓负向库存分录，不过总账。
- **副产物行**：挂在入库条目下的子行，必挂同一条目的副产物清单行；审核写本公司仓正向数量分录，无金额（同生产入库第一期先例）。
- **已收数量**：订单条目上默认单位累计，委外入库与采购入库审核加、作废减；委外入库复用**入库超收比例**容差（供应链设置·采购 Tab）。条目挂来源履约需求行时，同一事务沿「入库条目→订单条目→需求行」回写需求行已收数量，累计已收 ≥ 需求数量则需求行自动已完成（见 [履约需求](./履约需求.md)）。
- **已对账数量**：入库条目上默认单位累计的已对账量，由采购对账单生效加、回退减；剩余可对账＝入库数量−已对账数量。见 [采购对账](./采购对账.md)。
- **公司默认过账科目（入库）**：按公司可配入库借/贷默认值；入口「采购管理 → 采购设置」（先选公司再编），与采购入库共用。

## 功能清单

### 列表视图

- 页面分两个 tab（子路由，URL 可直达）：**入库条目**（默认视图，行级明细——公司、入库单号、入库日期、入库状态、订单号、对手、行快照口径的物料编号/名称/规格/客户料号、单位、数量、折算数量（默认单位）、入库仓库、已对账数量；默认按入库日期倒序）与**入库单**（整单列表，含审核/作废/删除动作）。
- 两个 tab 共用同一个入库单抽屉（新增/查看/编辑三态）；「新建入库单」入口两个 tab 都有；入库条目 tab 草稿单提供行操作「审核整单」，与入库单 tab 的「审核」一样先弹整单条目核对确认框。
- 菜单：采购管理 → 委外 → 委外入库。

### 入库录入

- 头（表头区）：公司（新建必选，创建后不可换）、入库单号（留空按编号规则自动取号，也可手填；独立系列）、入库日期（默认当天，可改即补录）、过账日期（有金额审核时必填，默认入库日期）、对手（供应商/内部公司，不能是单据公司自身，须与所引委外订单一致）、默认入仓/默认外协仓（均可空，仅成品行/副产物行/材料扣减行的新建与带出预填）、备注（对内，带入库存分录摘要）。
- 表底（低于条目表）：借方科目（自选：存货/费用等）、贷方科目（强制「未开票应付」角色）——**草稿保存即必填**；新建时按该公司默认过账科目整组代入（可改，无默认则留空）。
- 成品行：从委外订单条目选择器取行——选择器只列同公司、同对手、**已审核委外订单**且未收数量大于零的条目；单位可空＝订单行单位，数量大于零，行仓必填（本公司启用叶子仓），行备注；可跨多张委外订单，但公司、对手、原币须一致。
- **比例带出**：成品行保存（仅新建）时，按该条目的发料清单/副产物清单数量 ×（本行折算数量 ÷ 条目订购默认单位数量）自动创建材料扣减行与副产物行（6 位小数，折算后 ≤ 0 的清单行不带出）；带出是**一次性代入**——带出后是独立行，可自由增删改，改入库数量不自动重算。
- 材料扣减行：材料/单位以发料清单行为准锁定，数量可改；外协仓可空（草稿允许，审核时必填且限绑定当前对手的外协仓）。
- 副产物行：物料/单位以副产物清单行为准锁定，数量可改；入仓可空（草稿允许，审核时必填，本公司启用叶子仓）。
- 头关键字段锁：已有入库条目时公司/对手不可再改（须先删行）。

### 审核

- 仅草稿单可审核；审核前必须至少有一行入库条目。
- 审核同一事务内三个副作用**同生同灭**（同一库存分录组）：成品入本公司仓（正向分录）＋材料扣减（外协仓负向分录，不过总账）＋副产物入本公司仓（正向数量分录，无金额）。
- 复检：各行仓、材料扣减行外协仓、副产物行入仓逐行可用；各行订单仍为已审核委外订单；**超收校验**——累计已收（含本单）≤ 订购默认单位数量 ×（1 + 入库超收比例）。
- 过账金额按订单条目快照本币含税金额 × 本行折算数量占订购默认单位数量的比例汇总；大于零时写总账两行（贷未开票应付角色科目、带对手；借选定科目），为零则**跳过总账**（头上借贷科目仍须已填）。
- 按行累加订单条目**已收数量**（默认单位口径）。
- 审核后单据锁死：无反审核、无关闭态。

### 作废

- 仅已审核单可作废：全部库存分录与总账分录打作废标记（作废减库存，照常过负库存校验），已收数量同步扣减回滚。
- 任一条目存在非零**已对账数量**的入库单不可作废，须先撤回/作废相关采购对账单（见 [采购对账](./采购对账.md)）。
- 仅草稿单可删除，入库条目及其材料扣减行、副产物行随单一并删除。

### 与订单交叉

- 采购订单的「收发货历史」tab 同时列出委外入库行（与采购入库/委外发料同表，见 [采购订单](./采购订单.md)）。
- 已关闭订单不可再委外入库；存在已审核委外入库时订单不可作废，存在草稿委外入库时须先删除。

## 业务流程

委外订单（已审核、已发料）→ 新建委外入库单（选公司与对手，配/代入借贷科目）→ 从委外订单条目取行定成品入库量与入仓（系统按比例自动带出材料扣减行与副产物行，按需手改）→ 保存草稿 → 审核（成品入仓＋外协仓扣料＋副产物入仓＋加工费挂未开票应付）→ 采购对账勾稽后开票（见 [采购对账](./采购对账.md)）→ 出错在审核前改删，审核后作废重开（已进对账的不可作废）。
