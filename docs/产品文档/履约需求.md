# 履约需求

## 概述

履约需求模块是销售承诺与车间/采购执行之间的**内部需求中间层**。计划员将多张销售订单条目（可跨单）勾选纳入，或手工建无客户来源的独立需求（如参展样品）；确认后锁口径。行上**不再选择单一履约方式**——如何消化数量由**安排**子表表达，同一行可混用生产、采购、委外、库存与关闭。

边界：库存/关闭安排只登记意图、不扣库存不建单；不排有限产能；界面可称「需求单」，勿称「物料需求单」。

## 核心概念

- **履约需求单**：头状态 草稿 → 已确认 → 已关闭（+作废）；仅草稿可改可删；有未作废下游（生产工单、已审核未作废采购/委外订单条目、手工安排）时不可作废。见 [术语表](../../CONTEXT.md)。
- **履约需求行**：物料 + 数量 + 需求日 + 可选销售来源；**无行级履约方式**。
- **安排**：行上出口事实，类型 = 生产 / 采购 / 委外 / 库存 / 关闭。生产/采购/委外由工单创建或采购·委外订单审核**倒写**；库存与关闭手工维护。
- **已安排数量 / 已完成数量**：行上两个只读主投影（默认单位）——已安排看占坑，已完成看履行（含库存/关闭即完成）。采购分量可另显已下单/已收细分。
- **需求超安排比例**：行级超安排容差；关闭安排不吃容差。
- **销售占用**：已确认未作废需求单上有销售来源的行，Σ base 数量 ≤ 订单条目订购 base（草稿不占、确认占量）；作废释放占用。

## 功能清单

### 建单与行维护

- 选择公司、业务日期、备注；新建时业务日期默认当天，单号可留空自动取号或手填。
- 需求行与需求单基本信息在同一录入页面连续展示；从「需求行」列表也可直接新建整张需求单。
- 草稿可增删改行：物料、单位（限默认/转换单位）、数量（>0）、需求日、可选来源销售订单条目、行备注（**无履约方式字段**）。
- 手工行无销售来源合法；有来源时硬校验不超该条目可占用。
- 可跨多张已审核未关闭销售订单勾选纳入；同一销售条目可拆成多条需求行。
- 新建可「保存」或「保存并审核」。

### 安排子表

- 已确认需求行展示安排子表：类型、数量、下游单据链接（工单号/订单号等）、状态。
- **生产**：创建生产工单时倒写；工单作废释放。
- **采购 / 委外**：采购或委外订单审核挂本来源行时倒写；订单作废释放。草稿订单不占已安排。
- **库存**：手工加行，保存即占已安排与已完成，不扣库存。
- **关闭**：手工加行，数量硬卡 ≤ 剩余可安排（不吃超安排比例），保存即占已安排与已完成。
- 列表展示已安排数量、已完成数量、剩余可安排。

### 审核 / 关闭 / 作废

- **审核**：至少一行；审核成功后状态进入已确认并锁定行物料数量等口径。
- **关闭**（整单）：仅已确认可关；关闭后不可再新安排（不可再开工单/勾选下单/加库存关闭安排）。
- **作废**：仅已确认且无未作废下游时可作废；草稿请直接删除。作废释放销售占用。

### 行完成

- 自动完成：可安排剩余 ≤ 0（受需求超安排比例）且已完成数量 ≥ 需求数量。
- **无**行级「点完成」按钮；放弃用关闭安排，现货用库存安排。

### 权限与编号

- 独立权限资源（计划侧）；写操作进审计；编号规则可配。
- 手工新增或删除库存/关闭安排时，操作者必须同时具备需求单修改权限与需求行所属公司的数据授权；不能凭安排 ID 或需求行 ID 跨公司操作。

## 业务流程

1. 计划新建草稿需求单，手工加行或从销售勾选，确认。
2. 车间从行开（多张）工单 → 倒写生产安排；采购勾选带入下单审核 → 倒写采购/委外安排；计划可对手工库存/关闭安排。
3. 入库回写已完成；排满且履行完 → 行自动完成。整单可关闭收敛待办。
