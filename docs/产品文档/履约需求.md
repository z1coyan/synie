# 履约需求

## 概述

履约需求模块是销售承诺与车间/采购执行之间的**内部需求中间层**。计划员将多张销售订单条目（可跨单）勾选纳入，或手工建无客户来源的独立需求（如参展样品）；每行选定履约方式，确认后锁口径，再按行分流到自制工单或其它登记完成路径。车间不直接碰销售订单与客户。

边界：第一期外购/委外不自动建采购单或委外单；不排有限产能；界面可称「需求单」，勿称「物料需求单」。

## 核心概念

- **履约需求单**：头状态 草稿 → 已确认 → 已关闭（+作废）；仅草稿可改可删；有未作废生产工单时不可作废。见 [术语表](../../CONTEXT.md)。
- **履约需求行**：物料 + 数量 + 需求日 + 履约方式 + 可选销售来源；数量与单位折算为默认单位口径。
- **履约方式**：自制 / 外购 / 委外 / 库存。仅自制派生生产工单；外购/委外/库存由计划点「已完成」离开待办。
- **销售占用**：未作废需求单上有销售来源的行，Σ base 数量 ≤ 订单条目订购 base（含草稿）；作废释放占用。

## 功能清单

### 建单与行维护

- 选择公司、业务日期、备注；单号可留空自动取号或手填。
- 草稿可增删改行：物料、单位（限默认/转换单位）、数量（>0）、需求日、履约方式、可选来源销售订单条目、行备注。
- 手工行无销售来源合法；有来源时硬校验不超该条目可占用。
- 可跨多张已审核未关闭销售订单勾选纳入；同一销售条目可拆成多条需求行。

### 确认 / 关闭 / 作废

- **确认**：至少一行；确认后锁口径，仅草稿可再改头与行物料数量等。
- **关闭**：仅已确认可关；关闭后不可再生成工单或点完成。
- **作废**：仅已确认且无未作废生产工单时可作废；草稿请直接删除。作废释放销售占用。

### 非自制点完成与改履约方式

- 外购 / 委外 / 库存：已确认单上待安排行可点「已完成」。
- 自制行不可直接点完成（须经生产入库完工回写）。
- 已确认、未完成、无未作废工单的行可改履约方式。

### 权限与编号

- 独立权限资源（计划侧）；写操作进审计；编号规则可配。

## 业务流程

1. 计划新建草稿需求单，手工加行或从销售勾选。
2. 确认后：自制行待安排 → 车间生成工单；外购/委外/库存 → 计划点完成。
3. 自制经生产入库完工后需求行自动已完成；整单可关闭收敛待办。
