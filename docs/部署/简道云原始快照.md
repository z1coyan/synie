## 5. 以后怎么用

1. **重洗业务数据**：新应用读 `raw/*.json` 与 `master/*.json`；**2025-03 之前出库↔订单**读 `old-app/`（自制 UUID）。字段含义先看 `catalog/widgets/`，旧应用用 MCP `member_app_entry_widget_list`（`app_id=618b8f19e0305b00087fddf4`）。表单/字段坐标也见《[简道云数据迁移](./简道云数据迁移.md)》。拆行残留：`.scratch/jdy-migration/scripts/cleanup_split_fragments.py`。
2. **重挂附件**：按 `jdy-to-oss.jsonl` 的 `oss.file_id` / `oss.key` 写 `sys_attachment`，不要对 OSS `put` 新对象。
3. **补库存期初**：出库/入库/委外原始数量在 `raw/ship_*`、`pr_*`、`os_*`；按方案 D3 实盘后再走手工出入库，不要用上一轮 payloads。
4. **补会计凭证**：期初欠款、流水、发票、承兑原文在 `raw/opening_ar.json`、`bank_tx.json`、`invoices.json`、`bills.json`；过账规则仍按方案三轨（在途走 API、已结清不过账、期初凭证找平），避免和已导入的期初凭证双计。
