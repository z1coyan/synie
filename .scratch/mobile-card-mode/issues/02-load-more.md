# 02 — 加载更多翻页

**What to build:** 卡片模式的翻页从数字分页器改为「加载更多」：列表底部按钮显示「加载更多（已加载 N/共 M 条）」，点击按 offset 拉下一页追加到已有卡片之后；搜索/筛选/排序/fixedFilter 任一变更时累积数据清空、从第 1 页重新加载；已加载数量 ≥ 总数时按钮消失；追加请求失败时 toast 报错、已加载卡片保留、按钮可再次点击重试；「每页条数」选择器在卡片模式不渲染（追加步长沿用当前 pageSize 默认值即可）。加载更多状态迁移收敛为纯函数（输入当前累积/总数/查询变更事件，输出新累积与下次请求参数）并配自检。

**Blocked by:** 01 — 卡片流最小闭环

**Status:** ready-for-agent

- [x] 搜索/筛选/排序/fixedFilter 变更后列表重置回第 1 页，累积数据清空重新加载
