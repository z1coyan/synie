# 01 — 待办数据模型与骨架（prefactor）

**What to build:** 打平后续所有待办改动的地基——新建**待办表**（物化存储，同已发/已收/已对账数量投影先例）与**待办用户痕迹表**两表及对应 Ash 资源。待办表字段：类型枚举（开票/收票）、源单据多态引用（source_type+source_id，同 GL poly-ref 先例无真外键）、公司、对手快照、金额快照（对账单本币合计）、状态（active/closed）、产生/关闭时点、触发操作人。痕迹表：`(todo_id, user_id)` 唯一，存已读时点、忽略时点、以及忽略**复位基准**（源单最近一次状态变化时点）。两表均不落币种（取本币合计单一快照）。配部分唯一索引兜底「一张对账单同一时刻至多一条 active 待办」。本票无生产者，待办列表为空，但骨架可被查询/已读/忽略动作调用。演示：迁移通过、两资源可读写、空列表按权限圈人过滤返回空。

**Blocked by:** None — can start immediately
