# 05 — 待办前端：铃铛 + 菜单 + 列表

**What to build:** 让用户在界面上看到并处理待办——**顶栏用户区铃铛**（外观切换/用户菜单同区）：未读数徽标 + 下拉最近 N 条 + 「查看全部」入口；**独立待办菜单**：完整列表，活跃/历史双 tab，行内显示类型（开票/收票）、对账单号、对手、公司、金额、产生时间、已读态、「草稿关联中」徽标、忽略操作；点击待办**跳转**到对应对账单抽屉/详情（跳转即标记已读）。**刷新**：Phoenix PubSub 推送「戳」（类型 + 公司 + 计数增量），在线前端收到后拉详情刷新徽标；进页面/点铃铛时拉取兜底，复用现有 `SynieWeb.PubSub` 与 Ash notifier 视图广播通道。演示：挂着页面，别人确认一张对账单→铃铛即时亮未读数；点待办跳对账单；忽略后该条从我列表消失。
