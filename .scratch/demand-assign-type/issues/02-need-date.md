# 02 — 单头需求日（默认值+批量带入）与行需求日必填

**What to build:** 履约需求单头新增可空**需求日**：填了之后新增需求行的需求日自动带入（可手改）；单头提供「批量带入」入口，把头值一次性刷到全部既有行（覆盖已填值）；改单头本身不追溯既有行。需求行的需求日改为**必填**，草稿保存即拦（不是审核才拦）；勾选销售条目带入的行同样默认取单头需求日。批量带入不新增端点，随聚合草稿整体保存生效。

**Blocked by:** None — can start immediately

**Status:** ready-for-human

- [x] 需求单头新增需求日列（date，可空）；meta 声明并进 Grid/打印目录
- [x] 需求行需求日迁移回填（空值取单头需求日、再退业务日期）后设 NOT NULL
- [x] service 在行创建/更新保存时校验需求日必填，返回明确校验错误
- [x] 前端：新建需求行（含勾选销售条目带入）需求日默认取单头需求日；行编辑中需求日为必填
- [x] 前端：「批量带入需求日」按钮把头值刷进草稿行集合，随整体保存生效；改单头不动既有行
- [x] 服务层 PG 集成测试覆盖：行需求日空拒存、头需求日持久与回读、批量带入经草稿保存生效
