# 03 — 需求行来源字段创建定型、编辑只读

**What to build:** 需求行的**来源销售订单条目**与**来源生产工单**在创建时定型，之后任何编辑都不可改：编辑态只读展示（可见但不可修改）；创建路径（勾选销售条目带入、工单派生写入）照常可写；手工增的行不可事后补挂来源——想换来源就删行重勾。更新路径携带不同来源值的请求被 service 明确拒绝（同值重放放行，兼容整单草稿回传）。
