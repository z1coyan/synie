# 04 — 「配置菜单」Sheet 与角色页入口

**What to build:** 让管理员全程在界面完成菜单配置，不再碰 API：角色列表新增行操作「配置菜单」（按 `sys.role_menu:read` 门控，与「配置权限」入口并列；内置角色打开为只读），打开独立菜单配置 Sheet——按「模块 → 组 → 菜单项」三级展示真实菜单树，叶子复选框才落库、父级三态复选框仅作批量勾/清快捷；顶部状态徽标明示「未配置（全部可见）/ 已限制 N 项」，一键清空恢复全部可见；白名单中存在目录外的已失效 code 时，树外列出「已失效 N 项」提示并可一键清理；保存走整体同步，目录外 code 被后端拒绝时逐个点名展示。勾选/三态/序列化/失效识别抽成纯逻辑并有单测。

**Blocked by:** 02 — 角色菜单白名单后端（读写端点）；可与 03 并行

**Status:** ready-for-agent

- [ ] 角色列表出现「配置菜单」入口；无 `sys.role_menu:read` 不见；内置角色只读（可查看不可改）
- [ ] Sheet 三级树与真实菜单逐项一致（模块→组→项，含标签）
- [ ] 仅叶子复选框参与提交；父级三态（全选/半选/不选）推导正确，勾父=批量叶子
- [ ] 状态徽标：空集合显示「未配置（全部可见）」，非空显示「已限制 N 项」；一键清空可恢复
- [ ] 已失效 code 在树外提示并可一键清理（清理后保存即移除）
- [ ] 保存成功刷新状态；后端拒绝（目录外 code/内置角色）时报错可读
- [ ] 树勾选/三态/序列化（只含叶子）/失效识别为纯逻辑并有单测
