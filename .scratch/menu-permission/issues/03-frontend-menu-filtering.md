# 03 — 前端菜单过滤生效

**What to build:** 让白名单在用户导航里真正生效：新增白名单过滤纯函数——输入菜单模块树与有效菜单码集合，空集合原样返回（零行为变化）；否则按白名单保留叶子、剪掉空组与空模块、模块默认跳转页重算为首个可见项路径。应用外壳三处渲染（一级图标栏 / 二级面板 / 移动抽屉）统一走这一个派生，不在各渲染点各自过滤；会话信息类型扩展 `menuCodes` 字段（拉取失败维持 fail-closed 口径）。交付后：用 API 给某角色配上白名单，该角色用户登录即只看到裁剪后的菜单——第一个用户可感知的效果。URL 直达行为不变（不拦，纯呈现）。

**Blocked by:** 02 — 角色菜单白名单后端（`menuCodes` 来源）
