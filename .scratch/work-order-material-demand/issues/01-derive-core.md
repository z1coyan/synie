# 01 — 派生核心链路（生成物料需求动作 + 需求行工单来源）

**What to build:** 车间主任在「进行中且已挂 BOM 快照」的生产工单上点「生成物料需求」：弹窗逐行展示快照配料（毛需求 = 净用量×(1+损耗率)×工单 base 数量，即理论耗用口径；默认数量=毛需求、可手改），逐行（可批量）选去向——某车间 / 采购 / 不需要；提交后按去向分组生成多张履约需求单**草稿**：每个目标车间一张（头已填下发车间）、采购向一张（下发为空）。派生行带「来源=生产工单」只读链接（与销售来源互斥、不占销售占用）、需求日默认=工单需求日、单位沿用配料行、服务端复算 base 与快照；草稿照常取号、写审计；动作在工单上留 `generate_material_demand` 审计痕。需求行列表/抽屉可见来源工单号链接（受读权限与数据范围约束）。无 BOM 快照配料行的工单点动作得到明确报错；已完工/已作废工单不可执行。本票默认数量只按毛需求，参考库存在 02 接入。

**Blocked by:** None — can start immediately
