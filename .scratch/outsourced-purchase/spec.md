# 委外采购（outsourced-purchase）规格

Status: ready-for-agent

经 `/grilling` 逐问定案的委外加工功能规格。术语已入根 `CONTEXT.md`，决策理由见 [ADR 2026-07-24 委外采购](../../docs/adr/2026-07-24-outsourced-purchase.md)。产品文档按约定在实现交付时同步（只写代码已实现的行为），届时需更新：`docs/产品文档/采购订单.md`、`生产BOM.md`、`库存物料.md`，新增 `委外发料.md`、`委外入库.md`，并登记 README 模块表。

## 范围

采购订单勾选**委外标记**后，条目可配置成品 BOM 引用、发料清单（新子表）、副产物清单（新子表），选 BOM 自动代入；配套新增**委外发料单**与**委外入库单**两张执行单据；外协仓升级为绑定协作方的实义仓；BOM 取消一物料至多一张的唯一键。

## 定案明细

### 1. 核心语义

- **委外订单**＝勾选委外标记（`is_outsourced`）的采购订单，不是新单据类型，与常规/零星**正交**：常规委外条目仍强制有效采购报价引用（报价即加工费报价），零星委外手填加工费。
- 订单条目＝委外回来的**成品**，条目含税单价＝**加工费单价**。
- 委外标记新建期可勾选，**保存后锁死**（换标记只能删草稿/作废重开）。
- 订单状态机、双币金额链、条目快照、关闭/作废规则全部沿用普通采购订单。

### 2. 条目下的委外配置（全部可选，不配不挡开单）

- **成品 BOM 引用**：可空，限选**条目物料自身的 BOM**，仅作来源留痕、无活引用。
- **发料清单**（新子表，挂条目下）：材料＋单位＋数量＋行备注。选 BOM 后按 **理论耗用＝净用量×(1＋损耗率，空按 0)×条目数量** 折算代入。
- **副产物清单**（新子表，挂条目下）：材料＋单位＋数量＋行备注。按 BOM 副产品行 **单位产出量×条目数量** 代入。
- 两子表均为**快照复制**：代入后与 BOM 脱钩、可自由增删改；改条目数量**不自动重算**；BOM 后续变更不回溯。
- 发料清单行冗余**已发料量**受控投影（材料默认单位口径，发料审核加/作废减）；**超发不硬拦**、无容差设置，超额仅展示。
- 无发料清单的条目不做硬校验——委外发料取行时自然卡住。

### 3. BOM 主数据变更（推翻 2026-07-22 ADR 部分定案）

- 取消「一物料至多一张、以物料为唯一键」；一物料可多张。
- BOM 加**独立编号**（挂编号规则，留空自动取号可手填，全局唯一，创建后不可改）＋可空**方案名称**。
- 既有 BOM 数据需补编号；工艺路线/配料行/副产品行仍随各张 BOM 私有。

### 4. 外协仓（术语升级）

- 外协仓＝**我方**公司的仓，`is_outsourced=true` 时必挂**协作方**（Party 多态，限供应商/内部公司，一仓绑一方）。
- **账目不跨公司**：协作方为内部公司时也进「绑定该内部公司的我方外协仓」，对方自行录手工出入库单（同采购入库不镜像先例）。
- 委外单据的外协仓选择器只列**绑定当前对手**的外协仓。

### 5. 委外发料单（`pur_outsourced_issue`，权限码 `purchase.outsourced_issue`）

- 无金额、不过总账（仓间移动、所有权不变，同手工调拨先例）。
- 头：公司＋对手（供应商/内部公司，须与所引委外订单一致）＋发料日期＋头调出仓/头外协仓（可空仅新建行预填）＋备注＋单号（挂编号规则，独立系列）。
- 行：必挂**发料清单行**（带出材料与单位快照）＋数量＋行调出仓（必填，本公司启用叶子仓）＋行外协仓（必填，限绑定当前对手）＋行备注；可跨多张委外订单，全部行订单公司、对手须一致（无金额，无币种约束）。
- 状态机 草稿→已审核→（已作废），仅草稿可改可删，无反审核、无关闭态；审核同一事务写「调出仓负＋外协仓正」库存分录并累加已发料量；作废回滚，照常过负库存校验。
- 菜单供应链库存组（与采购入库同组），列表双 tab（发料条目默认/发料单）。

### 6. 委外入库单（`pur_outsourced_receipt`，权限码 `purchase.outsourced_receipt`）

- 独立单据，**财务完整镜像采购入库**：借贷科目槽草稿保存即必填、按公司默认过账科目整组代入、贷方强制「未开票应付」角色、本币金额为零跳过总账、双币金额链按订单条目快照折算。
- 行必挂委外订单条目；审核累加条目**已收数量**（`received_qty`）并复用**入库超收比例**容差；行冗余**已对账数量**进采购对账条目池（加工费照常对账→开票）；有非零已对账数量的行其入库单不可作废；订单「收货历史」tab 同时列出委外入库行。
- 审核同一事务同时：
  - **成品**入本公司仓（正向库存分录）；
  - **材料扣减**：按发料清单快照 ×（本次成品入库量 ÷ 条目需求数量）比例带出、可手改，写外协仓负向分录、不过总账；
  - **副产物入库**：按副产物清单同比例带出、可手改，写本公司仓正向数量分录、无金额（同生产入库第一期先例）。
- 状态机 草稿→已审核→（已作废），仅草稿可改可删；作废回滚全部库存分录、总账分录与投影，照常过负库存校验。
- 菜单供应链库存组，列表双 tab（入库条目默认/入库单）。

### 7. 明确不做

- 履约需求行（履约方式=委外）**不联动**，仍只登记意图；将来加生成入口属纯增量。
- 库存 v1 不记金额：材料物化成本、副产物估值随库存金额账一并设计。
- 不做批次/工序报工；不改订单状态机与审核流程；工序级外协（BOM 工艺路线的外协标记）仍不产生单据。
