# 02 — 外协仓实义化（绑定协作方）

**What to build:** 外协仓由占位标记升级为实义仓：仓库标记 `is_outsourced=true` 时必挂协作方（Party 多态，限供应商/内部公司，一仓绑一方）。仓库表单可维护外协标记与协作方；提供「按对手过滤外协仓」的选择能力（委外单据选外协仓时只列绑定当前对手的仓）。账目不跨公司——协作方为内部公司时同样进我方外协仓，对方自行录手工出入库单（同采购入库不镜像先例）。外协仓结存即协作方处我方材料结存，经库存余额表自然呈现（本工单不含任何库存分录变动，那是 04/05 的事）。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 仓库 `is_outsourced=true` 时协作方必填，`false` 时协作方必须为空
- [ ] 协作方为 Party 多态引用，限供应商/内部公司两类，一仓绑一方
- [ ] 仓库表单可设置/修改外协标记与协作方（沿用仓库既有可改惯例，受常规约束）
- [ ] 提供按对手过滤外协仓的查询/选择能力，供委外单据复用
