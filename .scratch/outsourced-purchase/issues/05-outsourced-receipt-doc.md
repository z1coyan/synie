# 05 — 委外入库单

**What to build:** 仓管用委外入库单登记协作方送回的成品，行必挂委外订单条目。财务行为完整镜像采购入库：借贷科目槽草稿保存即必填、按公司默认过账科目整组代入、贷方强制「未开票应付」角色、双币金额链按订单条目快照折算、本币金额为零跳过总账（仍要求科目已填）。审核同一事务内三个副作用：成品入本公司仓（正向库存分录）＋材料扣减（按发料清单快照 ×（本次成品入库量 ÷ 条目需求数量）比例带出、可手改，写外协仓负向分录、不过总账）＋副产物入库（按副产物清单同比例带出、可手改，写本公司仓正向数量分录、无金额）。审核累加订单条目已收数量并复用入库超收比例容差；行冗余已对账数量进采购对账条目池（加工费照常对账→开票），有非零已对账数量的行其入库单不可作废；采购订单「收货历史」tab 同时列出委外入库行。状态机 草稿→已审核→（已作废），仅草稿可改可删；作废回滚全部库存分录、总账分录与投影，照常过负库存校验。权限码 `purchase.outsourced_receipt`；菜单供应链库存组，列表双 tab（入库条目默认/入库单）；接入通用打印模板体系。

**Blocked by:** 02 — 外协仓实义化；03 — 采购订单委外标记与条目委外配置（不依赖 04——入库单不引用发料单，材料扣减按发料清单快照比例带出）
