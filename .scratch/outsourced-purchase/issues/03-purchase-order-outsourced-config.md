# 03 — 采购订单委外标记与条目委外配置

**What to build:** 采购订单头可勾选委外标记（新建期可勾，保存后锁死，换标记只能删草稿/作废重开），勾选后订单即委外订单：条目＝委外回来的成品、条目含税单价＝加工费单价。常规委外条目照常强制有效采购报价引用（报价即加工费报价），零星委外手填加工费；订单状态机、双币金额链、条目快照、关闭/作废规则全部沿用普通采购订单。条目下可配置：成品 BOM 引用（可空，限选条目物料自身的 BOM，仅作来源留痕）、发料清单子表（材料＋单位＋数量＋行备注，行上带已发料量投影字段，本工单只建字段、投影逻辑在 04）、副产物清单子表（材料＋单位＋数量＋行备注）。选 BOM 后按 理论耗用＝净用量×(1＋损耗率，空按 0)×条目数量 代入发料清单、按 单位产出量×条目数量 代入副产物清单；两子表均为快照复制——代入后与 BOM 脱钩可自由增删改，改条目数量不自动重算，BOM 后续变更不回溯。委外配置全部可选，不配不挡开单（无发料清单的条目在委外发料取行时自然卡住）。订单表单 UI 完整支持上述配置。

**Blocked by:** 01 — BOM 放开一物料多张（条目要按编号指名同物料多张 BOM 之一）
