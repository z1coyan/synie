# 01 — BOM 放开一物料多张（独立编号＋方案名称）

**What to build:** 同一物料可以建多张 BOM，每张 BOM 以全局唯一的独立编号为唯一键（挂编号规则，留空自动取号可手填，创建后不可改），另有可空方案名称辅助区分同物料的多张配方；既有 BOM 数据由迁移补齐编号。工艺路线/配料行/副产品行仍随各张 BOM 私有。BOM 表单与列表展示编号和方案名称，选择器里同物料多张 BOM 可凭编号/方案名称区分。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [x] 一物料可创建多张 BOM，不再以物料为唯一键（推翻 2026-07-22 BOM 模块 ADR 该项定案，依据 ADR 2026-07-24）
- [x] BOM 有独立编号：挂编号规则、留空自动取号可手填、全局唯一、创建后不可改；编号规则随迁移种子
- [x] BOM 有可空方案名称字段
- [x] 迁移为既有 BOM 数据补齐编号（无需人工返工）
