# 02 — 审核全有或全无校验

**What to build:** 存在装箱行的发货单审核时，在既有审核事务内按物料分组（默认单位口径）比对「Σ 装箱行 base ＝ Σ 该物料全部发货条目 base」：漏装任一物料、任一物料不等、装箱行含发货外物料，均整单拒审，报错点名物料与两侧数量并透出到抽屉可读；整表不填则跳过校验照常审核；草稿保存不校验（同超发/超收容差先例）。审核通过后装箱行随单锁死的语义在本票补验证。

**Blocked by:** 01 — 装箱行端到端骨架

**Status:** resolved

- [x] 无装箱行跳过校验；草稿保存不校验
