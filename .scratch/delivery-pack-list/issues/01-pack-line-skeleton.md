# 01 — 装箱行端到端骨架：发货单上能录、能看、随单锁

**What to build:** 用户在发货单草稿的「装箱清单」区（条目表下方）增删改装箱行——箱号（必填自由文本）＋物料（从本单发货条目的物料中带出筛选）＋单位（限默认单位或转换单位）＋数量（>0）＋行备注，系统折算 `base_qty`（6 位）并随折算展示；保存后重开抽屉可见，行保存冻结物料文本快照（编号/名称/规格/客户料号/单位名，不复制图纸挂接），主数据后改不回溯；审核后子表随单只读；删除草稿发货单级联删装箱行；新增行默认带入上一行箱号（边装边录）。无 `sales.delivery` 相应动作权限者不可读写装箱行（权限目录不新增资源码）。**本票不含审核校验**——发货单审核对装箱行照常放行，校验见票 02。

**Blocked by:** 无 — 可立即开工

**Status:** resolved

- [x] 箱号必填、数量 > 0、单位限默认或转换单位、系统折算 base_qty
