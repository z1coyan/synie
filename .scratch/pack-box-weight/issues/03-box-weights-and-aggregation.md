# 03 — 箱级重量：箱毛重、箱净重聚合与重量单位

**What to build:** 装箱箱上补齐重量三件套：**箱毛重**（可空手填，整箱过磅实测）、**重量单位**（引用重量类计量单位，默认该类型基准单位，可改）、**箱净重**＝Σ 箱内行净重按单位换算比例折算到箱重量单位，只读（不落库或受控投影均可，对外只读语义不变）。同箱行净重单位不同（如 kg 与 g）时聚合正确折算；改箱重量单位后箱净重折算跟随。重量全部可空；审核不做任何重量硬校验（含不设「毛重 ≥ 净重」拦截）；不建皮重概念。口径见 `CONTEXT.md`（箱净重 / 箱毛重）。

**Blocked by:** 02 — 行净重：推导、手改与落库（箱净重是行净重的聚合，行净重须先存在）。

**Status:** ready-for-agent

- [ ] 箱上可手填箱毛重（可空），审核后随单锁死
- [ ] 箱重量单位默认重量类基准单位、可改（限重量类单位）
- [ ] 箱净重＝Σ 箱内行净重，只读展示，随箱内行增删改实时正确
- [ ] 同箱异单位行净重经换算比例正确折算到箱单位
- [ ] 改箱重量单位后，箱净重按新单位折算展示
- [ ] 整票无重量可照常保存、审核；审核无任何重量硬校验
- [ ] 域服务层 Postgres 集成测试覆盖聚合、异单位折算、箱单位切换、可空审核
