# 02 — 行净重：推导、手改与落库

**What to build:** 装箱行新增**行净重**（该行物料总净重，可空）与**行净重单位**（不开放手改）。草稿期录入时按推导规则自动填值：行单位本身是重量类 → 直接按行换算折算；否则物料恰有一条重量类单位转换行 → 经它折算；物料有多条重量类转换行 → 默认空。推导来源存在时，数量/单位/物料变化即无条件重算覆盖（不弹确认）；无来源时这些变化不触碰手填值。行净重单位随推导来源单位、无来源默认重量类基准单位。用户可手改实测值，落库后随审核冻结；物料换算后改不回溯。不存在任何「保存时提示新增/修改物料换算」的交互。服务端只存落库值、不重算。口径见 `CONTEXT.md`（行净重、行净重推导）。

**Blocked by:** 01 — 装箱箱实体落地与装箱 tab 箱/行两级重构（行模型与装箱 tab 交互须先就位）。

**Status:** ready-for-agent

- [ ] 行单位即重量类时，行净重＝行数量按行换算折算（三分支之一）
- [ ] 物料恰一条重量类转换行时，行净重经该行折算正确；多条时默认空
- [ ] 有推导来源时改数量/单位/物料，行净重无条件重算覆盖手改值
- [ ] 无推导来源时改数量/单位/物料，手填值保持不动
- [ ] 行净重单位：有来源随来源单位，无来源默认重量类基准单位，UI 不可编辑
- [ ] 行净重可空；可手改实测值；落库随审核冻结
- [ ] 落库后修改物料换算系数，历史行净重不回溯
- [ ] 全链路无回写物料换算的提示或动作
- [ ] 域服务层 Postgres 集成测试覆盖推导三分支、单位规则、冻结不回溯（重量数值 3 位小数）
